边缘位置图像缩放
模块：CDN

图像因设备而异分辨率不同，但数据大小不变，因此会浪费不必要的资源。为了防止用户浪费资源，请使用 Lambda@Edge 对调整尺寸后的图像进行缓存并提供给用户。首先，为了评分，请创建一个拥有 admin 权限、可以使用 awscli v2、jq、curl 并且能够远程访问的 bastion 实例。
使用 S3 创建存储桶，使部署的文件不发生变形，并且 index.html 文件位于根目录。以此作为源站，在 CloudFront 中进行部署，并根据以下要求适当使用 Lambda@Edge、CloudFront Function、Caching。
请求 /images 路径的文件时，设置 width 和 height 参数，使其能够据此进行缩放。之后使用相同参数请求相同图像时，必须从 CloudFront 的缓存服务器而不是源站获取，并且 /index.html 不得被缓存。此外，访问 /index.html 和 /images 以外的路径时，请重定向到 /index.html。
CloudFront Function 请使用 cloudfront-js-2.0 开发，Lambda 运行时请使用 nodejs 20.x 或 Python 3.9。
Lambda 函数名称：wsi-resizing-function
S3 存储桶名称：wsi-static-<4words>
示例：
- /images/resize_test.jpg

-> resize_test.jpg (原始)

- /images/resize_test.jpg?width=400&height=500

-> resize_test.jpg(400x500)

- /dev/secret

->(重定向) /index.html
