模块: 13) Elastic stack
应用程序通过 Python Flask 开发。应用程序运行时绑定的端口为 TCP/5000。日志保存在 log/app.log（相对路径）。部署到 App EC2，并且从 Bastion 服务器发送请求时应能响应。（curl <AppEC2IP>:5000/log）
Bastion EC2 用于评分，并且必须具有 admin 权限。
OpenSearch Dashboard 应能通过 Web 浏览器访问。配置为不传递 /healthcheck 路径的日志。配置应用程序日志通过 fluent-bit 发送到 opensearch，并可通过仪表板查看。
（在 OpenSearch Dashboards 的 discover 项中，table 必须包含 clientip, method, path, protocol, responsecode, time, useragent）
