EKS Node Name: wsc2025-app-node

提供可访问应用程序Pod的Endpoint。Endpoint应确保外部访问无问题，即使Pod重启或增加，也应能正常访问。

LoadBalancer Name: wsc2025-cicd-alb

3) WAF
概述
使用AWS WAF配置阻止Web攻击的系统。Region使用us-east-1。
课题说明
许多Web应用程序基于用户传递的值执行数据库查询。在此过程中，如果对输入值的有效性验证不足，恶意查询语句可能被直接执行，这可能导致SQL Injection (SQLi)攻击。SQLi是一种严重的安全漏洞，攻击者可通过操纵数据库查询进行认证绕过、数据泄露、数据更改/删除等攻击。使用WAF对输入值进行有效性验证，并阻止恶意查询语句。

2. Network Firewall

在 Egress VPC 的 firewall 子网中创建 Network Firewall，所配置的 AWS Network Firewall 通过多层安全策略，系统性地控制发往外部互联网的流量。该系统实现了三级防御机制。

首先，通过无状态（Stateless）规则引擎阻断所有 ICMP（ping）协议流量，从而阻止网络扫描和基于 ping 的攻击。这作为第一道防线，阻断网络层（L3）的基本安全威胁。

其次，在有状态（Stateful）规则引擎中，为强化 DNS 安全，阻断所有使用 UDP/TCP 53 端口的外部 DNS 查询。由此强制仅使用内部已批准的 DNS 解析器，同时防止 DNS 劫持攻击和数据泄露风险。此外，还会阻断通过 IP 直接访问或 HTTPS 加密流量进行的绕过访问。

跨 2 个可用区配置为高可用。

Firewall Name: wsc2025-firewall

3. Bastion

为进行动作测试，在 App VPC 中创建 EC2 Instance，Name Tag 创建为 app-bastion。为进行评分，必须能够通过 SystemManager 访问，若无法访问，可能会对评分产生不利影响。
