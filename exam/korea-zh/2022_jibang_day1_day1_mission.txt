云计算 第1题 2 - 3

3. 基本设计
1) 需要创建两个 VPC。(VPC_A, VPC_B)
2) VPC_A 必须各有一个 public subnet 和一个 private subnet。
3) VPC_B 必须有一个 public subnet 和两个 private subnet（可用区 a、可用区 b）。
4) EC2 实例总共四个，bastion 必须位于 public subnet，service 用实例必须位于 private。(bastion 用实例名称为 Bastion_A、Bastion_B，service 用实例为 Service_A、Service_B)
5) 创建实例时，镜像使用 Amazon Linux 镜像。
6) Service_B 必须与 Private ALB 连接。
7) ELB 必须与 internal Route53 连接。（地址设置为 “service.internal”）

4. 网络与安全
1) VPC_A 和 VPC_B 必须建立 VPC peering。
2) VPC_A 设置为 CIDR(10.2.0.0/16)，VPC_B 设置为 CIDR(10.4.0.0/16)。
3) 创建实例时，Service_A 和 Bastion_A 使用相同的密钥对创建，Service_B 和 Bastion_B 使用相同的密钥对创建。
4) Service_A 实例必须只能通过 Bastion_B 访问。
5) Service_B 实例必须只能通过 Bastion_B 和 ELB 访问。
6) 在 Service_B 实例上实现 Web 服务器。（使用 apache 2 包，使用 80 port，返回 200 ok returen）
7) 从 Service_A 向 Route53(“service.internal”) 地址发起 http 调用时，必须收到 200 返回。
8) Security Group 必须设置为最小范围，以提高安全性。
9) 选手需将以下内容填写在答题纸上并提交。
Bastion_A public IP
Bastion_B public IP
Service_A private IP
Service_B private IP
Service_A, Bastion_A 密钥对
Service_B, Bastion_B 密钥对
