云计算 第2题 2 - 4

3. 使用 Fluent-bit 和 Fluentd 收集应用程序日志
模块: 14) EKS 可观测性
1. Bastion
- 创建用于评分的 Bastion EC2，Bastion 必须能够以集群管理员权限正常访问 EKS Cluster。
- 为了评分，必须在 Bastion EC2 的实例 IAM Role 中添加 AdministratorAccess 策略。
2. 应用程序
- 给定的 Source Code 和 requirements 文件不可修改，Dockerfile 可以修改。
- Application Source Code 必须构建为容器镜像并上传到 ECR。
- Application 将日志保存到相对路径 log/app.log。
- Sidecar Fluentbit 镜像必须使用 fluent/fluent-bit:latest。
3. 日志记录
- 每个 Application 必须通过 fluent-bit sidecar 将日志发送到 fluentd。
- Fluentd 必须部署为 DaemonSet。
- Fluentd 需要添加 CloudWatch Logs Plugin，因此改用已安装该插件的 fluent/fluentd-kubernetes-daemonset:v1.10.3-debian-cloudwatch-1.0 镜像。
- Fluentd 必须将收集到的日志发送到 CloudWatch Logs。
- 必须能够在 CloudWatch Logs 中于 30 秒内查看 Fluentd 发送的日志。
