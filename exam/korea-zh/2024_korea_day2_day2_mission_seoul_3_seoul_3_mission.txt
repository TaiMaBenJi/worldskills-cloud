云计算 第 2 任务
◦ IAM security maintenance system
Module: IAM security

请创建可远程访问的 EC2 Instance。Bastion 实例必须具有 admin 权限，并且能够使用 curl、jq、awscli v2。
创建 IAM user “tester” 作为用于测试策略的用户。为该用户创建并应用 AdministratorAccess 托管策略，以及 mfaBucketDeleteControl 策略：若未启用 MFA，则无法删除 S3 存储桶。
另外，创建用户组 “user_group_kr”，并将 “tester” 包含到该组中。假设韩国使用的所有 user 都属于 “user_group_kr”，请创建一项允许用户仅访问 ap-northeast-2 区域资源的策略 regionAccessControl，并使其应用于韩国的所有用户。
必须阻止对全球服务等外部区域资源的所有访问。
