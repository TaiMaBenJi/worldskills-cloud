3. EC2
使用 EC2 配置 Bastion 服务器。为了访问 Bastion 服务器，使用 TCP 2220。
- Instance 名称: wsi-bastion-ec2
- 子网：公有子网
- 安装包：AWS CLI v2, jq, curl
- Instance Type: t3.small
- EC2 IAM Role：创建一个对所有资源具有 full access 的 role，并将其附加。

4. IAM
创建 IAM 用户后，配置为登录账户时自动将登录日志保存到 CloudWatch。将管理员权限关联到 IAM 用户，使其可以使用所有服务。
- IAM 用户名：wsi-project-user
- IAM 权限：AdministratorAccess Policy
- 允许访问 AWS Management Console

5. CloudTrail
创建 CloudTrail，这是一个能够监控账户活动的服务，以便 IAM 用户通过控制台登录时能够将登录日志保存到 CloudWatch。
- 标签：Name=wsi-project-trail

6. CloudWatch
CloudWatch 参考以下要求创建日志组。
CloudWatch 日志流中不得存在除登录日志以外的其他日志。
登录日志必须在登录后 4 分钟内保存到日志流中。
- 标签：Name=wsi-project-login
- 日志流名称：wsi-project-login-stream
- 日志格式：{ USER: “<登录的 IAM 用户名> has logged in!” }
- 示例）：{ USER: “wsi-project-user has logged in!” }

7. Lambda
使用 Lambda 配置为：当 CloudTrail 中发生登录触发时，自动将日志保存到 CloudWatch。
- 标签：Name=wsi-project-log-function
