云计算 第2课题 1 - 3

o 使用 FluentBit 的 EKS 可观测性
模块: 14) EKS 可观测性
创建一台 EKS Cluster 和 Node Group。使用 EC2 作为 Worker Node，不另行配置扩缩容。所有容器必须由 wsi-ns namespace 管理。Pod 的日志使用 Fluent-Bit 配置，并使用 Sidecar Pattern 保存日志。保存到 CloudWatch Logs 时，必须转换为以下日志格式进行保存。日志保存时间配置为按韩国时间保存，不另行设置 TimeZone。此外，日志配置为在 /logs/app.log 路径中生成日志。
将提供的 Python 应用容器化，并部署到 EKS wsi-ns namespace。通过 kubectl exec 命令访问容器时，必须能够访问 /app，并且容器配置为也可使用 curl 命令。即使不做任何设置，也要配置为至少运行 2 个。Default Container 指定为 "wsi-cnt"。
- EC2 名称 : wsi-bastion-ec2
- EKS Cluster 名称 : wsi-eks-cluster
- EKS 版本 : 1.29
- EKS Deployment 名称 : wsi-dpm
- EKS Container 名称 : wsi-cnt
- Fluent-Bit Container 名称 : fluent-bit-cnt
- CloudWatch Log Group 名称 : /wsi/eks/log/
- CloudWatch Log Stream 名称 : log-<Pod ID>
