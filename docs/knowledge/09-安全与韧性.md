## 知识地图

### 1. 身份与访问（现代安全的核心）
- IAM：最小权限、角色 > 长期密钥、条件键、组织 SCP
- **联邦与临时凭证**：OIDC（GitHub Actions → AWS 免密钥）、SSO
- 目录服务安全：Kerberos 攻击面（黄金票据概念）、LDAP over TLS
- 特权访问：跳板机（Bastion）、会话录制、JIT 提权
- **零信任**原则：永不信任、持续验证、微隔离

### 2. 网络与边界
- 分层防御：WAF → SG/NACL → 主机防火墙 → 应用
- **WAF 实战**（韩国赛直接考）：托管规则组（Common RuleSet）、**NoUserAgent_HEADER（无 UA 即 403）**、SQLi 规则（`' OR '1'='1` 被拦）、速率限制
- DDoS：Shield、CloudFront 吸收
- 出口控制：NAT/Egress-only、VPC Endpoint、Network Firewall 集中管控（韩国 2025 第1任务：Firewall Routing）
- 隔离：私有子网、跳板、VPN/私有链路

### 3. 数据与加密
- 加密三态：传输中（TLS）、静态（KMS/EBS/S3 加密）、使用中（概念）
- KMS 密钥策略与授权；**每服务独立密钥**（防守纵深）
- 证书生命周期：签发/轮换/吊销（OCSP/CRL）
- 密钥管理：Secrets Manager（轮换）、External Secrets（K8s 注入）
- 数据分类与保留策略、GDPR/个保法概念

### 4. 主机与应用加固
- CIS Benchmark 逐条（SSH 加固、su 限制、内核参数、auditd）
- SELinux/AppArmor（01 章超前部分联动）
- 补丁管理（unattended-upgrades、Patch Manager）
- 容器安全：镜像扫描（ECR/Trivy）、非 root 运行、只读文件系统、seccomp
- **供应链**：SBOM、签名（Cosign）、SLSA

### 5. 检测与响应
- 审计：CloudTrail（全 API 记录）、VPC Flow Logs、主机 auditd/Windows Event Log
- 检测服务：GuardDuty（异常行为）、Security Hub（合规基线）、Inspector（漏洞）
- 事件响应流程：识别→遏制→根除→恢复→复盘（**WSOS 标准原文："respond to incidents by applying given protocols"**）
- 取证基础：磁盘镜像、内存提取概念（本沙箱有完整工具链可练）

### 6. 韧性与容灾
- 高可用 vs 容灾 vs 备份（3-2-1 原则）
- RTO/RPO 与 DR 模式（备份还原/Pilot Light/Warm Standby/多活）
- 演练：定期恢复测试、游戏日（GameDay）
- 混沌工程：Litmus/Chaos Mesh 注入故障验证韧性

## 检验标准

1. 对一个现成架构做威胁建模：产出 STRIDE 表 + 缓解措施清单
2. WAF 实战：自建规则让 SQLi/XSS/无 UA 请求全被 403，正常业务不受影响
3. K8s 安全检查：跑 kube-bench + 修复 Top10 问题；NetworkPolicy 微隔离验证
4. IAM 审计：给定账号找出所有超权配置并给最小权限改造方案
