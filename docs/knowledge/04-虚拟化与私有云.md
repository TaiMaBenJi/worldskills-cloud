# 04 · 虚拟化与私有云（L4）

> 中国国赛的"主战场"（OpenStack），世界赛的"背景知识"。私有云考的是"懂原理 + 会部署 + 会排障"。
> 即使主攻公有云，理解 OpenStack 也会让你真正明白"云到底是什么"。

## 知识地图

### 1. 虚拟化基础
- 概念：Hypervisor（KVM/Xen/Hyper-V/ESXi）、全虚拟化 vs 半虚拟化（virtio）
- QEMU 与 KVM 的关系；`qemu-img` 镜像格式（qcow2/raw/vmdk）转换
- `virsh` 管理：定义/启动/快照/迁移；virt-install
- CPU 虚拟化（VT-x/AMD-V）、内存 overcommit、NUMA 基础
- 云-init / cloud image / user-data（**韩国赛大量使用：user_data.sh 引导 EC2**）
- 镜像制作：手动装 + 清理 + 通用化（比赛常考"制作公共镜像"）

### 2. OpenStack（中国国赛规定动作）
**核心组件地图**
| 组件 | 作用 | 比赛常见操作 |
|------|------|--------------|
| Keystone | 认证/目录 | 创建用户/项目/角色、token 排障 |
| Glance | 镜像 | 上传镜像、格式转换、可见性 |
| Nova | 计算 | 实例生命周期、虚机救援、冷/热迁移 |
| Neutron | 网络 | 网络/子网/路由/浮动IP/安全组 |
| Cinder | 块存储 | 卷创建/挂载/扩容/快照/备份 |
| Swift | 对象存储 | 容器/对象管理 |
| Horizon | 控制台 | Web 操作 |
| Heat | 编排 | 模板编排（YAML/HOT） |
| Ceilometer | 计量 | 监控计量 |

**部署方案**：先学"先电版"（国内比赛主流平台，CentOS），再对照 Kolla-Ansible/Packstack
**典型考题**（国内赛）：
- 基础环境：主机名/hosts/时间同步/免密/防火墙
- 组件部署与数据库初始化、消息队列 RabbitMQ、Memcached
- 创建实例全流程（网络→路由→镜像→规格→安全组→浮动IP→SSH 登录）
- 卷操作、快照、镜像属性
- 排障：数据库连不上、token 过期、rabbitmq 队列阻塞、MTU 问题

### 3. 其他私有云/虚拟化（对比理解）
- VMware vSphere/ESXi：世界赛环境构建用到（Packer + ESXi）
- Proxmox VE：中小规模主流
- oVirt / CloudStack：概念对照
- 超融合概念（vSAN/Ceph 一体）

### 4. 存储原理
- 块/文件/对象三种存储的区别与场景
- Ceph 架构（MON/OSD/MDS/RGW）、CRUSH 概念
- iSCSI/NFS 共享存储实验
- 快照与备份策略（全量/增量）

### 5. 容器化前夜
- LXC/LXD 与 Docker 的谱系关系
- 理解"虚机 vs 容器"隔离级差异 → 直接衔接 06 章

## 超前部分

- **KubeVirt**：在 K8s 里跑虚机（私有云与云原生的融合点）
- **OpenStack + Terraform provider**：把手动部署改成 IaC
- **超融合与软件定义存储**：Ceph 生产级运维（PG 调优、故障域）
- **云间迁移**：virt-v2v、AWS VM Import、容器化改造（rehost→replatform→refactor 路径）
- **私有云计量计费**：CloudKitty、FinOps 私有云版

## 检验标准

1. KVM 上 30 分钟：qcow2 镜像制作 → 注入 cloud-init → 起虚机 → SSH 登录
2. 多节点 OpenStack 手搭成功并创建实例，用 CLI 与 API 双通道完成
3. 能解释"一台虚机从点击启动到拿到 IP 的完整组件调用链"（Nova→Neutron→…）
4. 故意破坏 RabbitMQ/数据库，用日志定位并恢复（比赛排障模拟）
