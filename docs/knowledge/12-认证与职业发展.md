# 12 · 认证地图与职业发展

> 认证不是目的，是**学习进度的外部刻度**与**简历的硬通货**。比赛是"全栈极限运动"，认证是"专项马拉松"——两者互补。

---

## 12.1 认证路线图（按本体系层级排序）

### L1-L2 基础（入门）
- **LPIC-1 / Linux+**：Linux 基础验证（比赛前打底）
- **CompTIA Network+**：网络基础（或直接冲 CCNA）
- **CCNA**：网络工程硬通货（对 Module A/B 网络题直接有帮助）

### L3 企业服务
- **RHCSA / RHCE**（红帽系）：Linux 运维与自动化（RHCE 的 Ansible 部分与比赛 A15 对应）
- **Windows Server 认证（AZ-800/801）**：混合基础设施管理员

### L4 私有云/虚拟化
- **VMware VCP** / **RHOSP（OpenStack）**
- **LFCS/云原生基础**：Linux Foundation 系

### L5 公有云（比赛核心区）
- **AWS**：Solutions Architect Associate（SAA）→ **SAP（Professional）** → DevOps Engineer Pro；特殊方向 Security/Advanced Networking
- **Azure**：AZ-104 → AZ-305 / AZ-400
- **GCP**：ACE → PCA
- **华为云**：HCIA → HCIP → HCIE-Cloud（国内院校体系最爱）
- **阿里云**：ACP → ACE

### L6 容器与编排（含金量最高）
- **CKA**（管理员）→ **CKAD**（开发者）→ **CKS**（安全专家）
- **Helm**：无官方认证，但 CNCF 生态熟脸
- **Istio/Envoy 认证**：服务网格方向

### L7 自动化
- **Terraform Associate**（HashiCorp）→ Vault/Consul 系列
- **Ansible**：Red Hat Certified Specialist in Ansible Automation
- **GitHub Actions/GitLab CI**：动手作品 > 认证

### L8-L9 可观测与安全
- **Prometheus Certified Associate（PCA）**
- **CKS、CCSP、CISSP**（安全方向深耕）
- **FinOps Certified Practitioner**（成本方向）

### L10 前沿
- **AWS Machine Learning Specialty / Azure AI Engineer**
- **CNCF 各项目认证**（Cilium、Argo 等新认证层出不穷）

## 12.2 比赛与认证的互相加成

| 比赛内容 | 顺带可拿的认证 |
|----------|----------------|
| Module A/B 服务全栈 | RHCE、LPIC-2 |
| AWS 模块 + 韩国题 | SAA（几乎裸考可过）、SAP（需补深度） |
| EKS/GitOps 模块 | CKA（强烈推荐赛前拿）、CKAD |
| Terraform 自动化 | Terraform Associate |
| 监控/性能 | PCA |

**策略**：以 CKA + SAA 为"两门必拿"，赛前各刷 2 周；其余以赛代考。

## 12.3 职业发展路径（比赛之后）

```
云计算选手
 ├─▶ 云架构师（Solutions Architect）：架构设计/售前/迁移
 ├─▶ SRE/平台工程师：可靠性/自动化/平台（最匹配比赛技能）
 ├─▶ DevOps/云原生工程师：CI/CD/容器/编排
 ├─▶ 云安全工程师：09 章方向深耕
 ├─▶ 技术讲师/教练：世赛教练、企业内训（国内世赛专家组长路径）
 └─▶ 创业者/自由顾问：云迁移、成本优化咨询
```

**薪资参考（2026 年，一线城市，人民币/年）**：
- 云运维工程师：15-30w
- DevOps/SRE：25-50w
- 云架构师：40-80w+
- 云安全专家：35-70w
- 有竞赛奖项+认证的应届生：起薪普遍上浮 30-50%（世赛奖牌在国内多地有落户/编制/奖金政策）

## 12.4 国内世赛相关政策（选手必知）

- 世界技能大赛由人社部牵头，各省人社厅组织选拔；获奖选手与教练有明确奖励（奖金、职称、落户加分，各地细则不同）
- 第 48 届世界技能大赛（**WorldSkills Shanghai 2026**）在上海举办——**本土作战，中国代表团重点冲金项目**
- 国家队集训基地：山西职业技术学院、台州技师学院等（云计算项目）；技术指导专家组由中国专家组长牵头（2022 特别赛冠军陈新源、2024 里昂冠军黄佳杰均出自深圳技师学院体系）
- 院校选手路径：省赛 → 全国选拔赛 → 国家集训队（多轮考核）→ 正选 1 人 + 备选
