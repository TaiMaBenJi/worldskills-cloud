# 02 · 网络工程（L2）

> 云计算比赛的"云"下面全是网络。世界赛 Module A 的网络服务（DNS/防火墙/WireGuard/透明代理）与 Module B 的路由/VPN/DHCP 直接考网络硬功夫。

- [ ] 理解网络高可用：VRRP/keepalived、负载均衡原理（L4/L7）

## 知识地图

### 1. 协议基础（必须脱口而出）
- OSI 7 层 vs TCP/IP 4 层；封装/解封装
- 以太网/ARP、VLAN、STP（概念）
- IPv4：报头、分片、TTL、ICMP；**子网划分与 VLSM 手算**
- IPv6：地址类型（GUA/ULA/LL）、SLAAC、NDP —— **世界赛大量考双栈**（Module A 的 A04/A16 都涉及 v6）
- TCP：三次握手/四次挥手、状态机、窗口、拥塞控制；UDP
- 应用层：HTTP/HTTPS、DNS、DHCP、SMTP/IMAP、SSH、NTP、LDAP、SNMP

### 2. 路由与交换
- 静态路由、默认路由；动态路由协议概念（OSPF/BGP 够用即可）
- Linux 路由：`ip route`、多网卡策略路由 `ip rule`
- NAT：SNAT/DNAT/MASQUERADE（**Module A 的 A06 就是 SNAT 检查**）
- 端口转发（**A16：UDP/53、TCP/80、443 转发**）

### 3. 防火墙
- iptables 表链结构（filter/nat/mangle）、conntrack
- nftables 新语法；firewalld zone 模型
- 常见实战：端口开放、限速、日志、透明代理引流（**A08 透明代理**）
- 安全组 vs NACL vs 主机防火墙的三层防御（AWS 场景）

### 4. DNS（命题大户）
- 递归 vs 权威；区域文件语法（SOA/NS/A/AAAA/CNAME/MX/TXT/PTR）
- BIND 配置：主区、从区（**A04 从服务器**）、正向/反向（v4 与 v6 各一套 —— **A04-05 双栈反向区**）、区域传送（**Module B N W-SRV 的 secondary zone**）
- 递归解析器（A04-03、A13-02）、转发、DNSSEC 概念
- 排障：`dig +trace`、`rndc`、named-checkzone

### 5. DHCP
- DORA 流程；ISC dhcpd 配置（范围、排除、保留、选项 3/6/15）
- DHCP Relay（**Module B 的 PARIS-ROUTER 评分点**）

### 6. VPN 与隧道
- WireGuard（**A07：接口 + PSK 预共享密钥**）—— 现代首选，配置即代码
- IPsec site-to-site（**Module B 里昂：Paris ↔ Lyon 站点间 VPN**）
- OpenVPN/SSH 隧道基础；GRE 概念

### 7. 代理与负载均衡
- 正向代理、透明代理（**A08**）、反向代理
- HAProxy：frontend/backend/listen、ACL、header 注入（**A12-04**）、HTTPS 重定向（A12-05）、证书（A12-06）
- Nginx 反向代理对照
- Keepalived + VRRP 提供 VIP（**A12-07 检查 VIP 在听 web 流量**）
- L4 vs L7、健康检查、会话保持

### 8. 抓包与分析
- tcpdump 过滤器语法、抓包落盘、用 Wireshark 分析
- 常见案例：DNS 解析慢、TCP 重传、TLS 握手失败

## 检验标准

1. 任意给一个 CIDR（如 10.1.64.0/20），30 秒内说出：掩码、可用主机数、第 N 个子网范围
2. 白纸上画出并解释：一个数据包从浏览器输入域名到 HTTP 响应回来的完整路径（含 DNS/DHCP/TCP/TLS/HTTP 各阶段）
3. 用 WireGuard 在两台 VM 间建隧道并抓包验证加密流量
4. 配出 DNS 主从 + 双栈正反向解析，从服务器断主验证从区可用
