# 03 · 企业服务全栈（L3）

> 世界赛与传统 IT 强国的"基本功题区"。Module A（Linux）16 个子标准和 Module B（Windows）8 台主机几乎全部落在这里。
> **这一层的每一个服务都要"能配 + 能排障 + 能解释原理"三连。**

---

## 能力清单

- [ ] 独立搭建：Web、负载均衡、文件共享、目录服务、邮件、PKI/CA
- [ ] Linux 侧（LDAP/Samba）与 Windows 侧（AD/DFS/IIS）都能干
- [ ] 理解 Kerberos/NTLM、证书链、SMB 协议的工作机制
- [ ] 能把多个服务串起来（如：LDAP 认证 + Samba 挂载 + Web 证书 + 邮件 TLS）

## 知识地图

### 1. 目录服务（命题核心）
**Linux 侧 — OpenLDAP（Module A 的 A01）**
- DIT 树设计、schema（core/cosine/nis）、DN/RDN 概念
- `slapd` 配置、ldif 文件编写、`ldapadd/ldapmodify/ldapsearch`
- OU 结构（评分：`ou=Employees` 是否存在）、用户属性、登录验证
- 客户端集成：nslcd/sssd、PAM 认证

**Windows 侧 — AD DS（Module B 的 DC1/DC2）**
- 域/林/子域、OU/组/用户、AGDLP 授权模型
- **Fine-Grained Password Policy**（评分点：HR 组特殊密码策略）
- 通过 PowerShell 自动化创建用户（评分点：automated powershell script）
- 子域/子林（DC2: `lyon.paris.local` 子域）、安全组（REMOTE）
- 只读域控/GC 概念、站点

### 2. Web 服务
- Nginx 与 Apache：虚拟主机、反向代理、TLS、ACME
- IIS（Module B 的 WEB-SRV）：站点/虚拟主机、绑定、**HTTPS 无证书错误**（评分点）
- 静态内容、.htaccess/nginx conf 语法、日志分析
- HTTP 缓存语义、安全头（HSTS/CSP）

### 3. 文件共享
**Linux — Samba（A03）**：公共共享（匿名只读/可写）、内部共享（认证）、权限矩阵
**Windows — DFS（Module B FILE-SRV）**：
- `\\paris.local\CSDrive\Common|MKT|SALES|HR|TECH` 挂载点配置（逐个评分）
- 个人共享 + 配额（Quota）、可执行文件限制（评分点）
- **DFS 复制（DFSR）**
- 共享权限 vs NTFS 权限、ABE、离线文件

### 4. PKI / 证书体系（命题大户）
**Linux（A02）**：Root CA + 子 CA（services.pem）、按服务签发（web/mail 证书）、`openssl verify` 验证链
**Windows（WEB-SRV CA 评分点）**：AD CS 根 CA、证书注册（Enrollment）、SAN（Subject Alternative Name）
**通用**：
- X.509 结构、CSR/CRL/OCSP、证书链验证
- OpenSSL 全套操作：`genrsa/req/x509/verify/s_client`
- 内部 CA 实践：给内部服务（web/mail/LDAP/HAProxy）签发并部署
- **SSH 证书认证（A11）**：`TrustedUserCAKeys`——用户证书登录，取代密钥分发

### 5. 邮件系统（A09）
- Postfix（MTA）架构：队列、别名、转发
- Dovecot（IMAP/POP3）+ **STARTTLS（A16-03 检查 143 端口 STARTTLS）**
- 从命令行发信验证（`swaks`/`sendmail`），TLS 证书匹配
- 反垃圾概念：SPF/DKIM/DMARC

### 6. 高可用与反向代理（A12）
- HAProxy frontend/backend + 负载均衡算法 + 健康检查
- Keepalived VRRP 浮动 VIP
- header 注入（`http-request set-header`）、HTTPS 跳转、证书卸载
- Nginx keepalived 对照方案

### 7. Windows 域管理细节（Module B 评分点密集区）
- **GPO 全家桶**（十几项评分点）：
  - 登录消息横幅（Interactive logon message）
  - 环境变量（GPP Environment）、禁用本地管理员
  - 禁止 LM hash 存储（NoLMHash）
  - Windows Update 计划（GPP Scheduled Tasks）
  - 注册表访问限制、禁用 cmd/powershell/Run
  - 文件历史关闭、登录脚本（Tech 组自动启动 powershell）
- RRAS 路由与 DHCP Relay（PARIS/LA router）
- 反向代理角色（Windows 上配 reverse proxy）
- NPS/远程访问、RemoteApp（FILE-SRV 评分点）

### 8. 观察 2025 韩国题：企业服务在云上的形态
- 赛题不再直接考"手工配 AD"，而是在 AWS 上用托管服务实现同类能力：IAM ≈ 目录服务、S3 ≈ 文件共享、RDS ≈ 数据库、ACM ≈ 证书
- **映射思维**：把传统服务的概念映射到云托管服务（本资料包韩国/葡萄牙赛题都在考这个）

## 对应真题

| 服务 | 真题 |
|------|------|
| OpenLDAP/Samba/CA/邮件/HAProxy | 里昂 Module A 全套 |
| AD/DFS/GPO/IIS/ADCS | 里昂 Module B 全套 |
| 传统→云映射 | 葡萄牙 2024（CA/文件同步/NLB）、韩国 2021-2026 |

## 超前部分

- **SSO 现代化**：Keycloak/OIDC/SAML，把 LDAP 升级为身份联邦
- **cert-manager**：K8s 里自动签发/续期证书（把 PKI 玩成声明式）
- **Samba 高级**：AD DC 角色（Samba 4 可当域控）、`samba-tool` 自动化
- **Windows Server Core + PowerShell DSC**：声明式配置 Windows
- **邮件现代化**：MTA-STS、BIMI、多域 TLS 报告
- **文件服务前沿**：S3 协议网关、SMB over QUIC

## 检验标准

1. 90 分钟内从零搭出：OpenLDAP（含 OU 与用户）+ 用户能 SSH 登录（libpam-ldap）
2. 给两台无 AD 的 Windows Server 建域 + 子域 + 3 条 GPO 并验证生效（`gpresult /r`）
3. 自建两级 CA，为 web/mail 签发证书，`openssl verify` 全部 OK，浏览器无警告
4. HAProxy + Keepalived 双机，杀主节点 VIP 自动漂移且业务不断
