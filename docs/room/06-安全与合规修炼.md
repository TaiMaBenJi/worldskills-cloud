# 机房管理 · 06 安全与合规修炼

> 软件世界的安全天天上新闻；物理世界的安全——出事就是大新闻。
> 这一篇讲机房管理者的安全责任：从门锁到合规审计。

---

## 6.1 物理安全五层模型

```
第 1 层 园区周界   围墙/道闸/保安/车牌识别
第 2 层 建筑入口   前台登记/闸机/电梯分层控制
第 3 层 机房门口   门禁（刷卡+人脸）/双门互锁/视频
第 4 层 机柜      机柜锁/电子锁/钥匙台账
第 5 层 设备      带外网隔离/BIOS 密码/机箱锁/启动项锁
```

**每层的思维**：假设前面 N 层已破，第 N+1 层还剩多少防护力？
- 只有门禁没有登记 → 有人尾随进去也无记录
- 只有视频没有门禁 → 事后能看，事前无阻
- 机柜不锁 → 进来了就能拔盘（物理接触 = 最高权限）

### 关键设计：双门互锁与尾随防范

- **双门互锁**（mantrap）：第一道门关，第二道才能开——物理防尾随。
- 无互锁时：靠行为规范（一人一刷）+ 视频复核。
- 高风险区域再加：体重感应/金属探测（防带入危险品）。

## 6.2 等保 2.0 与机房（实操视角）

**背景**：中国的网络等级保护（等保 2.0）对机房有"物理安全"要求。学校/企业机房做等保测评时，机房部分是必查项。

**常见检查点（物理安全域）**：

| 类别 | 检查什么 |
|---|---|
| 位置选择 | 避免顶层/地下室/靠外墙（防水防雷防潮） |
| 物理访问 | 门禁系统 + 进出记录 + 专人陪同 |
| 防盗窃破坏 | 机柜锁、设备固定、视频覆盖 |
| 防雷击 | 接地系统检测记录 |
| 防火 | 灭火系统、警报、演练记录 |
| 防水防潮 | 漏水检测、排水、无渗漏 |
| 温湿度 | 空调系统 + 监控记录 |
| 电力供应 | UPS + 冗余线路 + 切换记录 |
| 电磁防护 | 屏蔽/接地（特殊场景） |

**检查的本质是"证据"**：不是"我们有门禁"，而是"这是近 3 个月的门禁记录 + 异常进出处理单"。**你的日常记录 = 检查时的得分。**

**准备姿势**（平时就该有的）：
1. 制度文档（出入管理制度、应急预案）成文
2. 记录留存：门禁日志、巡检表、演练记录、维保单
3. 整改闭环：每次检查发现的问题有"整改-验证"记录

## 6.3 审计与追溯：三个问题都能答

> 安全事件调查时，永远问三个问题：**谁进来了？谁动了设备？谁改了配置？**

| 问题 | 证据链 |
|---|---|
| 谁进来了 | 门禁记录（精确到秒）+ 视频 + 前台登记 |
| 谁动了设备 | 操作记录 + 视频（机柜正面）+ 变更单 |
| 谁改了配置 | 系统日志 + 堡垒机审计 + 变更台账 |

**实操要求**：
- 门禁/视频保存 ≥90 天（很多规范的最低线）
- 系统日志集中收集（别只存本地——机器被入侵时本地日志最不可信）
- 变更台账电子化（谁都能查，不能只有一个人知道）

**复盘推演练习**：假设"上周三机房少了一块硬盘"，你现有的记录能还原出什么？缺什么？

## 6.4 数据安全（介质维度）

### 硬盘退役：三种销毁方式

| 方式 | 做法 | 适用 | 成本 |
|---|---|---|---|
| 数据覆写 | 全盘覆写（多次随机/标准算法） | 盘还要复用 | 低 |
| 消磁 | 强磁场破坏磁记录 | 磁带/机械盘（SSD 无效） | 中 |
| 物理粉碎 | 机械粉碎/打孔 | 高敏感数据，盘报废 | 中高 |

**规则**：**含敏感数据的盘，只信"粉碎"**。SSD 覆写不可靠（磨损均衡+预留块），必须加密后销毁或物理销毁。

### 移动介质与备份加密

- 机房禁止私接 U 盘（或只允许白名单设备）
- 备份数据**加密存储**（否则备份介质被偷 = 全部数据泄露）
- 加密密钥与备份分开保管（别放同一个保险柜）

## 6.5 供应链与人员安全（最容易被忽略）

### 维保/施工人员管理

- **登记 + 陪同**：外部人员永远有人跟（哪怕只是"在门口看着"）
- **动火/动电审批**：电焊、切割等作业必须走审批 + 现场看护 + 灭火器就位
- **权限时效**：临时门禁卡当天收回；工作结束复核现场

### 内部风险控制

- **最小权限**：能只读就别给写，能操作一台就别给全部
- **双人原则**：高敏感操作（数据销毁/核心变更）两人在场
- **离岗移交**：员工离职/转岗当天完成权限回收 + 密码轮换清单
- **行为基线**：非工作时间的进出/登录要能解释

### 社会工程防范（软性但致命）

- "我是厂家工程师，来修空调的" → 查工单 + 联系对口部门确认 + 全程陪同
- "领导让我来拿块硬盘" → 任何数据介质带离必须有书面审批
- 电话索要密码 → **永远不通过电话/IM 给凭据**

## 6.6 安全检查清单（月度自检）

**物理环境**
- [ ] 门禁记录完整，无"未登记进入"
- [ ] 视频画面正常（抽查 3 个点位），保存天数达标
- [ ] 机柜锁完好，钥匙台账与实物核对
- [ ] 消防器材/气瓶压力正常
- [ ] 无违规堆放（纸箱/杂物）与私接用电

**操作与记录**
- [ ] 变更台账齐全，抽查 3 单有回滚方案
- [ ] 外部人员记录完整（登记+陪同+工单）
- [ ] 离岗人员权限已回收

**数据与介质**
- [ ] 待退役介质有清单与销毁计划
- [ ] 备份加密有效（抽验可解密）
- [ ] U 盘管控措施有效（抽查接口封禁/白名单）

## 6.7 自测与练习

1. 只有门禁没有视频，安全问题是什么？（无法复核"谁和谁一起进去的"——尾随无从查证）
2. SSD 为什么不能靠覆写保证数据清除？（磨损均衡把数据散在闪存颗粒+预留区，逻辑覆写不触达全部物理单元）
3. "等保检查只看制度文件"对吗？（❌ 查的是**证据**：记录、日志、检测报告——文件和记录必须对得上）
4. 维保工程师要单独进机房，你的流程？（拒绝单独进入——登记+陪同+书面工单三者缺一不可）
5. 备份加密后，密钥丢了会怎样？（数据无法恢复——密钥管理是备份体系的一等公民，双人保管+异地备份）

**动手练习**：为你熟悉的机房（真实的或假想的）写一份《出入管理制度》，包含：申请流程、陪同规则、记录要求、违规处理。500 字以内，能贴到墙上执行的那种。
