## 2.1 供配电深度修炼

### 2.1.1 从市电到芯片：完整架构图

```
主变电站A ──┐                ┌── 变压器 ──┐
            ├── 高压配电 ────┤            ├── 低压配电 ── ATS ── UPS ── 列头柜 ── PDU ── 设备
主变电站B ──┘                └── 变压器 ──┘
                                    │
                                  油机（发电机）
```

**四个关键词，按深度递进：**

| 架构 | 含义 | 单点故障 | 典型场景 |
|---|---|---|---|
| N | 单套系统 | 全挂 | 小办公室机房 |
| N+1 | 多一套备用（冗余 1） | 冗余件坏时无保护 | 企业机房（最常见） |
| 2N | 双套完全独立 | 无（理论） | 金融/核心业务 |
| 2(N+1) | 双套且各带冗余 | 无 | Tier IV 数据中心 |

**STS（静态转换开关）** vs **ATS（自动转换开关）**：ATS 机械切换（数十毫秒~秒级，用于市电互备）；STS 静态切换（毫秒级，用于 UPS 输出互备）。

**UPS 并机与 ECO 模式**：
- 并机 = 多台 UPS 并联共享负载（冗余 + 扩容）；并机调试是专业活，接线错误会环流。
- ECO 模式省电（效率 99%），但市电异常时靠旁路切换（有 2-10ms 风险）——**核心机房不用 ECO，别为省电赌可用性**。

### 2.1.2 负载计算实战（完整案例：50 台服务器的机房）

> 这是 L4 的核心技能：**从设备清单一路算到 UPS 选型与电池配置。**

**第 1 步：设备清单与功率统计**（一律用设备铭牌/手册上的功耗参数）

| 设备 | 数量 | 单台典型功率 | 小计 |
|---|---|---|---|
| 2U 服务器 | 40 | 450W | 18,000W |
| 存储 | 4 | 800W | 3,200W |
| 核心交换机 | 2 | 300W | 600W |
| 接入交换机 | 4 | 150W | 600W |
| 防火墙 | 2 | 250W | 500W |
| 监控/管理服务器 | 2 | 350W | 700W |
| **合计** | | | **23,600W ≈ 23.6kW** |

**第 2 步：系数修正**
- 同时系数（不是所有设备都满载）：取 0.8 → 18.9kW
- 需求系数（实际配置常低于铭牌）：再用铭牌算法时反而要小心**低估**——服务器满配+跑 AI 负载时可远超典型值。**保守原则：算电永远偏悲观**。
- 规划余量：×1.25（未来扩容 + 安全）→ **23.6 × 1.25 ≈ 29.5kW**

**第 3 步：UPS 容量选择**
```
UPS 容量(kVA) = 有功功率(kW) ÷ 功率因数(0.9~1.0)
              = 29.5 ÷ 0.9 ≈ 32.8kVA
```
近档选型：**40kVA 模块化 UPS** 或 **2×20kVA 并机（N+1 不够，做 2N 用两台独立 40kVA）**。
（模块化 UPS 的好处：按需扩容、单模块故障不影响整机。）

**第 4 步：电池后备时间**
要求：满载续航 30 分钟。
```
能量需求 = 负载(kW) × 时间(h) ÷ (逆变效率0.92 × 放电深度0.8)
        = 29.5 × 0.5 ÷ (0.92 × 0.8) ≈ 20 kWh
```
按 12V/100Ah 电池（单节 ≈ 1.2kWh 标称，实际放电容量打折）估算：约需 **20~24 节组串配置**（具体组数、串并联方式必须以**厂商电池计算书**为准——现场环境温度、老化系数、终止电压都会影响）。

**第 5 步：配电末端**
- 列头柜→机柜 PDU：按每柜实际负载布线，**三相尽量平衡**（不平衡度 <10%）
- 每机柜预留：当前负载 + 50% 余量；高密机柜（8kW+）单独规划

**产出：《电力规划计算书》**——把上面五步写成文档，附上"若满配 60 台服务器"的扩容预演。这就是你的 L4 作业。

### 2.1.3 电池系统：UPS 的"油箱"管理

- **阀控铅酸（VRLA）**：主流，寿命 3-5 年（高温环境更短），怕热（25°C 以上每升 10°C 寿命减半）。
- **锂电池**：能量密度高、寿命长（8-10 年），但**热失控风险**要求：BMS 必须可靠、消防要适配（锂电专用灭火）、温度监控到"每节"。
- **健康管理动作**（写进你的月度巡检）：
  1. 看：壳体鼓包/漏液/端子腐蚀 → 直接报修更换
  2. 测：内阻测试（季度）——内阻异常升高 = 容量衰减的前兆
  3. 试：放电测试（年度）——真刀真枪验证"标称 30 分钟到底能不能扛 30 分钟"
- **更换策略**：整组更换（混用新旧电池 = 木桶效应），别省这个小钱。

### 2.1.4 防雷与接地（工程要点）

- **三级防雷**：总配电（一级 SPD）→ 分配电（二级）→ 设备端（三级/PDU）。
- **等电位联结**：机柜、桥架、地板、管道全部接入同一接地网——**目的不是"接地"，是消除"电位差"**（电位差才会打坏设备）。
- **接地电阻**：A 级机房联合接地 ≤1Ω（GB50174 语境），普通按当地规范；每年雷雨季前测一次。
- **常见错误**：接地线串联（应该并联汇集到母排）、用零线当地线、螺接处生锈松动。

### 2.1.5 能效与电能质量

- **PUE = 机房总能耗 ÷ IT 设备能耗**。理想 1.0；传统机房 1.8-2.5；优秀 1.2-1.4。
- **降 PUE 行动清单**：提高送风温度（27°C 冷通道没问题，别一冷再冷）→ 封闭冷通道 → 变频改造 → 减少过度除湿 → 照明 LED 化 → 精确送风（按机柜）。
- **谐波**：大量开关电源带来 3/5/7 次谐波 → 变压器发热、中性线过载。对策：选用带滤波的 UPS（现代双变换 UPS 输入侧已好很多）、大机房评估有源滤波。

## 2.2 制冷深度修炼

### 2.2.1 热负荷计算（案例：与 2.1 同一间机房）

```
总热负荷 = 设备热负荷 + 围护结构 + 照明 + 人员 + 新风
```

| 来源 | 计算 | 结果 |
|---|---|---|
| IT 设备 | 近似 1:1 转热（23.6kW 电力大部分）= 23.6kW | 23.6 kW |
| 照明 | 10~20W/m² × 100m² | ~1.5 kW |
| 人员 | 100W/人 × 5 人 | 0.5 kW |
| 围护结构 | 按保温情况取 5~10% | ~2 kW |
| **合计** | | **≈ 28 kW** |

**制冷设备选型**：精密空调按显冷量选，取 1.2 倍余量 → **≈ 34kW 显冷量需求**。
配置方案：**3 台 15kW + N+1**（任意一台故障或检修时，两台 30kW 仍可覆盖常规负载；极端热浪时降载运行）。
> 注意：选型看的是**显冷量**（SHR 显热比越高越好，机房不希望空调用于除湿）。

### 2.2.2 精密空调系统形态

| 形式 | 特点 | 场景 |
|---|---|---|
| 风冷直膨（DX） | 室外机+室内机，简单 | 中小机房 |
| 水冷/冷冻水 | 中央冷源，效率高 | 大型机房/数据中心 |
| 双盘管 | 两路冷源冗余 | 高可用要求 |
| 间接蒸发/自然冷却 | 利用室外低温，省电 | 气候合适地区 |

**运维动作**：滤网清洗（月度）、加湿罐检查、冷凝水排水（防堵防漏）、室外机清洁（散热翅片）、压缩机轮巡（多台轮换运行、均衡磨损）。

### 2.2.3 气流组织：每一度电的归宿

**核心原理**：冷空气密度大在下、热空气在上；**让冷风只吹设备前脸，热风只从后部排走，永不混合**。

- **冷通道封闭**（顶板+端门）：效果最大的一步改造，通常直接降 3-5°C 冷通道温度差。
- **盲板**：空 U 位必须装——否则热回流。
- **高架地板**：开孔率只开在冷通道对应位置；地板下别当仓库。
- **上走线机房**：用"上送风+风管/风帽"定向送风。
- **巡检判断**：摸机柜前后温差（冷通道 22-25°C 手感凉、热通道明显热）；红外枪看机柜进风面热点。

### 2.2.4 环境标准与监控布点

**ASHRAE A1 推荐范围**（机房主流执行标准之一）：温度 **18-27°C**、相对湿度 **≤60%**（下限由静电控制，约 8% 露点以上）、露点 -9~15°C。

**传感器布点原则**：
- 每排机柜：冷通道、热通道各至少 1 组（进风面/回风面）
- 空调送风/回风口：各 1 组
- 死角与远端：1 组（验证均匀性）
- 数据进动环平台，**阈值告警：温度 30°C 警告 / 32°C 严重 / 35°C 紧急**（按业务自定，别等 40°C）

### 2.2.5 高密与液冷（前沿，L4+ 必须听过）

- 传统机柜 3-5kW；GPU/AI 机柜 20-50kW+ → **风冷物理极限**。
- **冷板式液冷**：冷却液流经芯片冷板，带走 70%+ 热量；改造要点：CDU（冷量分配单元）、管路与快接头、**泄漏检测**、机房承重、消防兼容。
- **浸没式液冷**：整机泡在绝缘液体里，PUE 可低于 1.1；成本/维护模式完全不同。
- 机房管理者的视角：液冷不是 IT 的事——**是机房的事**（承重、水、电、消防全要动）。

## 2.3 消防深度

### 探测链路（越早越好）

```
极早期（VESDA 吸气式）→ 烟感 → 温感 → 联动 → 灭火喷放
     ↑ 灵敏度最高          ↑ 主力      ↑ 确认
```
- **极早期探测**：连续吸气采样，可在"阴燃"阶段报警——重要机房标配。
- 双探测确认：通常"两种探测器同时报警"才触发喷放（降低误喷）。

### 灭火系统对比

| 系统 | 原理 | 设计浓度参考 | 特点 |
|---|---|---|---|
| 七氟丙烷 | 化学抑制 | ~8-10% | 主流，响应快 |
| IG541 | 窒息（降氧） | ~37-43% | 绿色，钢瓶多、占地大 |
| 气溶胶 | 化学 | 按厂家 | 小空间，残留问题 |

**工程要点**：喷放时间 ≤10 秒、房间**泄压口**（否则门炸开）、声光警报先行、**喷放后通风后人才进**。

**维护动作**：钢瓶压力月检、电磁阀/启动瓶年检、联动测试年检、全员会认警报声。

## 2.4 安防与动环深度

### 安防三件套
- **门禁**：刷卡/人脸/指纹 + 双门互锁（防尾随）+ 防胁迫码 + 消防联开（火警时自动解锁）。
- **视频**：门口/走道/机柜正面；存储 ≥90 天；关键画面单独归档。
- **入侵报警**：玻璃破碎/红外/门磁，非工作时段布防。

### 动环监控系统（机房"ICU 监护仪"）

**监控对象清单**（验收时逐项测）：
- 环境：温湿度（多点）、漏水（空调区/地板下/天花板）、烟感
- 电力：市电状态、UPS（输入/输出/电池/负载率）、配电柜（电压/电流/功率）
- 制冷：空调运行/告警/送风温度
- 安全：门禁记录、视频状态
- 消防：主机状态、探测器状态

**告警链路验收标准**：人为制造一个告警（洒水/断一路电）→ 从现场到值班人手机 ≤1 分钟，且信息完整（哪里、什么、多严重）。

## 2.5 基础设施验收清单（拿去就用）

**电力系统**
- [ ] 双路市电切换测试（ATS 手动+自动各一次）
- [ ] UPS：切换测试、电池放电测试报告、并机均流检查
- [ ] 配电：三相平衡实测、开关标识与图纸一致、PDU 标签完整
- [ ] 接地电阻实测报告 ≤ 设计值

**制冷系统**
- [ ] 单台空调停机测试（其余能否扛住，温度回升速率记录）
- [ ] 气流：冷通道温度均匀性测试（多点温差 <3°C）
- [ ] 漏水检测逐点测试

**消防安防**
- [ ] 双探测联动测试（不喷放，只验证逻辑）
- [ ] 钢瓶压力、泄压口、警报器
- [ ] 门禁+消防联动、视频存储天数抽查

## 2.6 自测与练习

**计算练习（必做）**：
1. 你的目标机房有 20 台 2U 服务器（每台 500W）+ 存储 2 台（1kW）+ 网络设备 1kW。算：UPS 容量、30 分钟电池需求、精密空调显冷量需求。（答案框架见 2.1/2.2 案例）
2. 一间 80m² 机房，PUE 当前 2.0，IT 负载 40kW。若降到 1.5，一年省多少电？（按 0.8 元/度算：年耗电差 = 40kW × 0.5 × 24 × 365 ≈ 17.5 万度 ≈ 14 万元）

**判断题**：
3. UPS 电池可以新旧混用吗？（❌ 木桶效应，整组换）
4. 冷通道温度 24°C 比 20°C 更"不专业"？（❌ 24°C 反而符合提高送风温度的节能方向，别盲目求冷）
5. 气体灭火喷放时人在里面只要屏住呼吸就行？（❌ 立即撤离，缺氧+分解产物，没有任何商量）
