# 机房管理 · 01 能力阶梯：L0-L5 标准与自测

> 这一篇解决一个问题：**你现在站在哪一级，下一步练什么。**
> 用法：先做 1.7 的快速自测（15 分钟）→ 找到自己的级别 → 从对应章节开始修炼。

---

## 1.1 阶梯总览与定级原则

| 级别 | 称号 | 一句话 | 核心特征 |
|---|---|---|---|
| L0 | 零基础 | 认识机房 | 知道"有什么、哪里危险" |
| L1 | 值班员 | 会看会记 | 能独立完成巡检与报告 |
| L2 | 运维工程师 | 会修会装 | 能独立处理常见故障 |
| L3 | 高级运维 | 会建会管 | 能设计系统、管容量、带值班 |
| L4 | 专家/主管 | 会规划会指挥 | 能规划机房、指挥应急 |
| L5 | 大师/首席 | 会定义 | 定标准、带团队、解决未知问题 |

**定级原则（重要）：**
- 级别看"**独立**负责能力"——有人带着能做的，不算达标。
- 每级达标 = 能力清单里 **80% 以上**能做到。
- 跳跃定级不现实：L3 的"设计能力"建立在你亲手处理过足够多 L2 故障之上。

---

## 1.2 L0 → L1：从"看见"到"值班"

### 能力标准（全做到 = L0 达标）

- [ ] 能说出机房七个子系统（供配电/制冷/消防/安防/机柜布线/计算存储/网络）及各自作用
- [ ] 知道机房三处"绝对不能碰"：**配电柜、UPS 电池、气体灭火钢瓶**——并知道为什么
- [ ] 理解并执行"安全观察三动作"：看灯、听声、闻味，发现异常**只记录、不上手**
- [ ] 会正确使用基础防护：防静电手环（或洗手/摸机柜放电）、不穿化纤衣服进机房
- [ ] 能读懂设备面板的基本指示灯含义（绿=正常、黄=警告、红=故障）
- [ ] 会写一条合格的异常报告（含五要素，见下）

**异常报告五要素**：时间、地点（哪个机柜/哪台设备）、现象（看到了什么）、影响（影响了什么）、已做处置。

### L0 自测（判断对错）

1. 机房听到刺耳蜂鸣，第一反应是打开 UPS 柜门检查电池。（❌ 先看告警面板，电池区严禁自行开箱）
2. 消防气瓶压力表掉到红区，可以先不管，等年检再说。（❌ 立即上报，这是预防失效）
3. 巡检发现某服务器面板黄灯，应该记录位置与现象并报告。（✅）
4. 为了凉快，可以把机房门敞开用走廊空调吹。（❌ 破坏温湿度控制+安全）
5. 手上戴着金属手表也可以直接插拔服务器硬盘。（❌ 静电与短路风险）

### 达标练习
到任意一台电脑/服务器前，蒙住"术语"，用大白话给别人讲清楚：面板每个灯、每个接口是干什么的。讲不出来 = 没达标。

## 1.3 L1 → L2：从"值班"到"能修"

### 能力标准

- [ ] 独立完成一次完整日检（温湿度/指示灯/告警屏/漏水/门禁/异响），用时 ≤20 分钟
- [ ] 会看监控系统：能说出每条告警的含义和第一处置动作
- [ ] 会安全地开关机（含带外管理远程开关机）、会进 BIOS、会看系统日志找线索
- [ ] 会用工具完成：`df` 查磁盘、`journalctl` 查日志、`ss` 查端口、ping/dig 查网络
- [ ] 会正确交接班：做了什么、发现什么、遗留什么，三句话说完
- [ ] 认识 RAID 级别并能说出"当前这台机器是 RAID 几、坏一块会怎样"
- [ ] 会写一份完整的巡检记录（模板化，可追溯到具体设备）

### L1 自测

1. 服务器亮红灯且蜂鸣，面板显示"PWR"——最可能是？（电源模块故障，检查冗余电源另一路是否带载）
2. 想重启一台"画面卡死"的服务器，正确姿势是？（先试带外管理软重启；不行再按电源键短按；最后才硬断电——每一步都要有理由）
3. `df -h` 显示 / 分区 100%，你的第一动作是？（不急着删文件——先定位什么在涨：du 从根目录逐层找，再看日志轮转和临时文件）
4. 交接班最不该漏的是？（遗留问题与未完成操作——比如"我关了一台服务器的电源准备换硬盘，还没装回去"）

### 达标练习
让同伴（或自己）故意给一台 VM 制造 3 个故障（占用端口/删配置/塞满磁盘），你在 30 分钟内定位并修复，全程记录。

## 1.4 L2 → L3：从"能修"到"能建"

### 能力标准

- [ ] 独立搭建一台 PXE 装机服务器（DHCP/TFTP/HTTP + 应答文件），批量装 5 台以上
- [ ] 独立部署一套监控（采集 + 告警到手机），并为关键指标设阈值
- [ ] 设计并执行备份方案：3-2-1、会算 RPO/RTO、**做过恢复演练**
- [ ] 会做容量评估：电力（当前负载/余量）、空间（U 位）、网络（端口/带宽）、算力
- [ ] 执行一次完整变更：方案 → 审批 → 窗口 → 执行 → 验证 → 记录（含回滚点）
- [ ] 会换硬件全流程：确认盘位 → 热插拔 → 盯重建 → 记录台账
- [ ] 能带一个新人完成值班（讲解 + 验收）

### L2 自测

1. RAID 5（4 块盘）坏了一块，多久内必须换？（逻辑上"尽快"——重建期间再坏一块就全灭；容量大时重建数小时，期间要降载并紧盯）
2. 备份策略："每天全量+保留 30 天"最大的问题？（容量与备份窗口爆炸；应用增量+定期全量+异地副本）
3. 变更窗口为什么选低峰期？（影响面最小 + 出问题时你有时间恢复 + 次日有人力支持）
4. 监控告警太吵怎么办？（分级 + 收敛 + 抑制规则；"每条告警都要有人管"，否则告警疲劳=事故之母）

### 达标练习
在你的训练场/虚拟机上从零完成一次"新服务器上线"全套：装机 → 配置 → 入监控 → 进备份 → 登记台账。全程留文档。

## 1.5 L3 → L4：从"能建"到"能规划"

### 能力标准

- [ ] 拿到需求（如"50 台服务器的推理机房"），能输出：配电计算书、制冷评估、机柜布局图、预算框架
- [ ] 懂冗余等级：N+1 与 2N 的区别，知道什么业务配什么等级
- [ ] 能组织一次应急演练（含脚本、分工、评估、改进闭环）
- [ ] 能指挥真实应急：决策（关谁保谁）、对外沟通（向领导/客户说什么）、记录
- [ ] 会做成本优化：PUE 分析、老旧设备退役计划、维保策略选择
- [ ] 能输出制度：巡检规范、值班制度、供应商管理（SLA）
- [ ] 培养出至少 1 名能独立值班的下属

### L3 自测

1. 一间机房标称 N+1 的空调系统，一台故障后还能维持吗？（能——N+1 的意义就是在线冗余；但此时无冗余，须尽快修复）
2. 领导问"机房电费为什么这么高"，你怎么回答？（用数据：IT 负载功耗 + PUE 拆解 + 趋势 + 三项优化建议与预期收益）
3. 应急预案评审最该检查什么？（每个场景的"第一动作"是否唯一清晰、责任人是否有备份、通讯录是否最新——演练是唯一验收）

### 达标练习
给自己虚拟一个 100 万元预算的机房改造项目，写出完整方案书（需求/方案/计算/预算/工期/风险），然后找懂行的人"答辩"。

## 1.6 L4 → L5：从"能规划"到"能定义"

### 能力标准

- [ ] 数据中心级设计能力：供电架构（2N/DR）、制冷方案（风冷/液冷）、Tier 等级与 RAS 分析
- [ ] 处理"教科书上没有"的问题：能从第一性原理推导方案（电学/热学/可靠性）
- [ ] 定义标准：编写企业级机房运维规范、验收标准、培训体系
- [ ] 培养体系：带出骨干、设计晋升路径、组织技术评审
- [ ] 行业影响力（加分项）：标准组织/社区/教学/评审

### L5 的本质
L5 不是"会更多设备"，而是：**面对任何新系统，能在几小时内建立正确的模型——知道它会在哪里坏、为什么坏、坏了怎么办。** 这个能力只能从"大量真实事故 + 深度复盘 + 系统思考"中来。

### L4 自测

1. 双路市电来自同一变电站的两段母线，算真冗余吗？（不算——上游还共享单点；真正的 2N 要追溯到独立变电站/发电机的源头多样性）
2. 液冷改造的最大工程挑战通常是什么？（不是冷板本身，而是：机房承重、CDU 管路、水质管理、泄漏检测与应急预案、消防适配——系统性工程）

## 1.7 快速自测（15 分钟定级）

对以下 12 条自问自答（"能独立做到"才算 ✅）：

**A 组（L1 门槛）**
1. 能独立完成一次日检并写出报告
2. 知道三类禁区并说出为什么
3. 看得懂面板灯与监控告警

**B 组（L2 门槛）**
4. 能独立定位并修复"网站打不开/磁盘满/服务挂了"这类常见故障
5. 会装机、会换盘（含重建观察）
6. 会看日志、会查端口、会看监控趋势

**C 组（L3 门槛）**
7. 独立搭过 PXE 批量装机或监控或备份体系（至少其一，且用过 1 个月以上）
8. 执行过带回滚方案的变更，并写过变更记录
9. 能做容量/风险评估并写成文档

**D 组（L4 门槛）**
10. 出过完整的机房方案（计算书级别）并被采纳
11. 组织过应急演练，或指挥过真实应急
12. 带过人（有明确的"我教出来"的下属）

**评分**：
- A 组全 ✅ → **L1**；A+B → **L2**；A+B+C → **L3**；A+B+C+D → **L4**；D 组有行业级输出 → **L5 候补**
- 每组里 2/3 达标 = 该级"基本达标"，还差的一项就是你的下一个练习目标。

## 1.8 定级之后：你的下一步

| 你现在 | 下一步主攻 | 配套动作 |
|---|---|---|
| L0 | 第 17 章全读完 + 01 篇过关 | 训练场 `task 6` 看一遍 |
| L1 | 02 篇（基础设施）+ 03 篇（硬件） | 训练场 Module 6 冲到 80 分 |
| L2 | 04 篇（部署）+ 05 篇（运维） | 训练场满分 + 自己的第一次变更 |
| L3 | 06 篇（安全）+ 07 篇（应急） | 组织一次桌面演练 |
| L4 | 07 深读 + 08（职业） | 输出一份自己的规范文档 |

> 记住：**级别是暂时的，习惯是永久的。** 无论你在哪一级，先保证"每次动手都有记录、每次事故都有复盘"——这两个习惯会把你自动推上更高的级别。
