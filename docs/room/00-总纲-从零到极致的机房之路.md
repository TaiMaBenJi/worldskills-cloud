## 0.1 先回答三个问题

### ① 机房管理是什么？

一句话：**让一个装着电、冷、火、网、铁的屋子，7×24 小时不出事——出了事也能迅速搞定。**

它是计算机世界里最"物理"的一份工作：代码工程师关心逻辑，网络工程师关心连接，而机房管理者关心的是——**这一切跑在什么上面、会不会突然没了。**

- 电：市电、UPS、配电、防雷接地
- 冷：精密空调、气流组织、温湿度
- 火：探测、气体灭火、联动
- 网：交换机、布线、分区
- 铁：服务器、存储、机柜
- 再加一个"看不见的器官"：动环监控与运维体系

### ② 它有多重要？

**AI 时代，机房不是在消失，而是在扩建。** 每一个大模型背后都是成排机柜、暴涨的功率密度、更复杂的散热。云计算的"云"字下面，是实打实的 UPS 和空调。

任何一间机房出事，损失都是六位数起步：一家小公司的机房烧了 = 公司数据没了；一所学校的机房瘫了 = 全校上不了课。**这就是为什么这个岗位"平时看不见、出事上头条"。**

### ③ 值不值得学？

对两类人极其值得：

1. **准备就业的学生**（比如你）：机房运维是 IT 行业里"门槛务实、天花板高"的方向——初级岗位要求清晰（会巡检、会装机、会排障），往上走是数据中心工程师、基础设施架构师。
2. **手上的系统要落地的人**：学云计算、学网络的人，最终都会撞上"物理层"——懂机房的人，比只懂软件的人多一个维度的竞争力。

> ⚠️ 但先说实话：这份工作**不是"天天高科技"**。它的大多数时间是巡检、记录、维护——**"稳定"是它的最高荣誉，"无聊"是它健康的表现**。能接受这一点、并从"把隐患消灭在摇篮里"中获得成就感的人，才能走远。

## 0.2 五级能力阶梯（总览）

从零到极致，分为 6 个阶段（L0-L5）。详细标准与自测见 01 篇，这里先给你全景：

| 级别 | 称号 | 一句话能力画像 |
|---|---|---|
| **L0** | 零基础 | 认识机房、知道危险在哪、能安全地做最基础的观察与记录 |
| **L1** | 值班员 | 能独立完成日常巡检、会看监控、会报告异常 |
| **L2** | 运维工程师 | 能独立处理常见故障、装机、换硬件、配置基础服务 |
| **L3** | 高级运维 | 能设计部署方案（PXE/监控/备份）、做容量与变更管理 |
| **L4** | 专家/主管 | 能规划一间机房（选型/配电/制冷计算）、指挥应急、带小团队 |
| **L5** | 大师/首席 | 能设计数据中心、制定标准、处理前所未见的危机、教出下一代 |

**关键认知：这六级不是"证书"，是"你能独立对什么级别的系统负责"。** 简历上写"精通"没用，能说出"我独立管过 N 台服务器/N 间机房的什么指标"才是真的。

## 0.4 极致是什么样（L5 的一天）

给你一个真实的想象场景，这就是这条路尽头的风景：

> **凌晨 2:47，手机告警：A 路市电中断，B 路也中断，UPS 已切换电池，预计续航 18 分钟。**
>
> L2 的人会紧张地打电话请示；
> L3 的人会按预案逐台安全关机，保住核心业务；
> **L4/L5 的人：** 先确认油机启动状态 → 计算负载已经过优化（非关键业务今晚本来就该下线维护）→ 指令轮流切换电源、监控电池温度 → 25 分钟后油机带载成功，业务零中断 → 事后 48 小时内交出复盘报告，并推动"电池健康度预测"立项。
>
> 整个过程中，他每分钟都在做**有依据的决策**——依据来自十年积累的计算、预案、演练和他对整套系统的"肌肉记忆"。

### 极致能力清单（L5 的画像）

- [ ] 拿到一张机房图纸，30 分钟内能说出它的冗余等级与主要风险点
- [ ] 从零规划一间机房的配电/制冷，给出经得起审计的计算书
- [ ] 任何告警看一眼，能排出"三种可能原因 + 优先验证顺序"
- [ ] 处理过的每个事故都有时间线、根因、改进项三件套的复盘
- [ ] 能在 10 分钟内组织起一支应急小组并分工（含对外沟通）
- [ ] 能用数据和领导谈预算：PUE 降 0.1 = 每年省多少电费，算给他看
- [ ] 带出过至少 2 个能独立值班的徒弟
- [ ] 见过的失败比大多数人做过的项目还多——且都写了下来

## 0.5 心法十条（贯穿全程的思维方式）

比技术更早建立的是观念。这十条会在后面每一篇里反复出现：

1. **责任 > 技术**。先保护人（撤离、断电），再保护数据，最后才是设备。任何时刻的优先级：**人 > 数据 > 设备 > 面子**。
2. **预案思维**。所有"万一"都要提前有答案。预案不是写给别人看的文件，是你凌晨三点不慌的底气。
3. **复盘文化**。事故是学费，复盘才是收获。没有复盘的团队会重复交同样的学费。
4. **变更纪律**。没有回滚方案的变更 = 赌博。改配置前备份、低峰期执行、改完验证——三步缺一不可。
5. **文档即资产**。U 位表、端口表、变更记录——你的文档质量 = 你离职后别人骂你还是念你。
6. **成本意识**。机房是"烧电的"，每度电、每个 U 位都是钱。会省钱的管理者才配管更大的机房。
7. **冗余是工程不是浪费**。单点 = 定时炸弹；N+1 不是奢侈，是数学。
8. **演练代替祈祷**。没演练过的预案 = 没有预案。
9. **简单可靠 > 花哨先进**。机房技术选择的第一原则是成熟度，不是新鲜度。
10. **持续学习**。设备每 5 年换代，标准每几年更新——这行的安全感来自学习速度。

### 物质准备

| 需要 | 具体 | 用途 |
|---|---|---|
| 一台电脑 | Windows/Mac/Linux 都行 | 装虚拟机练 Linux 和 PXE |
| 虚拟机软件 | VirtualBox（免费）等 | 模拟"服务器" |
| 手机训练场 | 本 App 的 wsarena | 随时真机练（`wsarena task 6`） |
| 纸笔/记事本 | 实体的！ | 画图、算数、记你自己的巡检表 |

### 心理准备

- 这行的日常是"无聊"与"惊险"交替出现——**学会享受"什么都没发生"**。
- 你会被要求做很多"琐事"（记录、贴标签、打扫）——它们是专业的组成部分，不是杂活。
- 前 3 个月你会觉得"我是不是在干体力活"——正常，几乎所有人都这么过来。
