> 目标读者：想从零基础一路打到世界技能大赛（WorldSkills）云计算项目金牌，并超越大赛水平的人。
> 本体系不只是一份"教程目录"，而是**以赛题为靶心、以超越为目标**的能力地图：每一层都写清楚"学什么、练什么、对应哪道真题、超出大赛的部分在哪"。

## 一、先读懂"比赛"本身（30 分钟读完，少走一年弯路）

### 1.1 这个项目是什么

- 世界技能大赛技能编号：**Trade 39 / Skill 39 - Cloud Computing**（旧文件里出现的 `WSC2016_TP39`、`wsc2024-t39-module-a` 中的 `39` 就是这个编号）
- 正式比赛项目自 WorldSkills 体系改革后独立成项；2022 年特别赛（Special Edition，韩国等地举办）起成为各强国必争项目
- 2024 里昂（Lyon）金牌：**中国 黄佳杰**；2022 特别赛金牌：**中国 陈新源**（深圳技师学院）；2026 年下一届：**上海（WorldSkills Shanghai 2026）**
- 主办方技术支持方：AWS 是 WorldSkills 的全球合作伙伴，比赛长期以 **AWS 公有云**为公有云平台
- 单届比赛通常 4 个模块（Module），每模块 3~7 小时，覆盖：Linux 系统、Windows/AD、公有云架构、自动化、故障排查

### 1.2 各模块实际考什么（以 Lyon 2024 真题为例）

| 模块 | 主题 | 真实考点（从官方评分脚本提取） |
|------|------|--------------------------------|
| Module A | Linux 基础设施 | LDAP、CA/PKI、Samba、DNS 主从、WireGuard、透明代理、邮件、fstab/备份、SSH 证书、HAProxy+VRRP、Ansible、防火墙端口转发 — **52 个评分点** |
| Module B | Windows Server | AD DS、DNS 区域/区域传送、GPO（十余项）、DFS、站点到站点 VPN、DHCP、RRAS 路由、反向代理、AD CS、IIS — **8 台主机、60+ 评分点** |
| Module C | 公有云架构（AWS） | 综合架构题：VPC 设计、计算/存储/数据库/网络、高可用、成本 |
| Module D | Troubleshooting | 拓扑 + 工单系统：环境里有预埋故障，按要求定位并修复（含 Debian/Windows 混合环境） |

> 详细评分点见 `test-projects/LYON2024-评分点全录.md`。

### 1.3 各国赛制差异（重要）

- **世界赛/欧洲赛**：更偏传统基础设施 + 网络服务 + 故障排查（Linux/Windows 都是重点），AWS 只是模块之一
- **韩国赛**（极强，多届奖牌得主）：AWS 全家桶 + Terraform + EKS + GitOps + 性能 SLO + 成本优化，**接近实战 SRE/平台工程**，题面精细到具体实例规格和 SLO 百分比
- **中国国赛（职业院校技能大赛云计算赛项）**：OpenStack 私有云 + 容器云 + 华为云/公有云三件套，偏向技术栈广度
- **葡萄牙/加拿大等**：混合型，AWS + 传统服务 + 自动化

**结论**：想拿到世界级水平，必须 **传统基础设施（Linux+Windows+网络服务）与云原生（AWS+K8s+IaC）两手都硬**。这也是本学习体系的结构依据。

```
L0  计算机常识 ──▶ 打字、英文文档阅读、基础数学

```

## 三、训练方法（比"看教程"重要 10 倍）

### 3.1 黄金循环：题目 → 裸做 → 对照 → 复盘

1. 拿本资料包里的真题（韩国题面最完整，评分标准明确）
2. **限时裸做**：不许查资料，像比赛一样
3. 对照官方评分标准/评分脚本逐项自检
4. 把失分点写成 checklist，下次训练先过一遍

### 3.2 必备训练环境

- 一个 AWS 账号（免费层不够，比赛内容需要真实额度；建议准备 $50-100/月训练预算或使用教学实验室）
- 本地：VirtualBox/VMware + 4-8 台 Linux VM（Debian/Ubuntu/CentOS）+ 2-4 台 Windows Server VM
- 推荐工具链：`terraform`、`ansible`、`kubectl`、`helm`、`awscli`、`docker`
- 时间分配参考：世界赛每个模块 3-7 小时，训练时按模块限时

### 3.3 评分思维（竞赛的秘密）

- 世界赛评分是"**子标准(Aspect) → 子项(Criterion) → 模块**"树状结构，每个子项 0.1~0.5 分
- 很多评分点是**功能测试**而非"配置对比"：评分脚本大概率通过命令实测（LDAP 能登录吗？证书链对吗？HAProxy 真的负载均衡吗？）
- 所以备考要**以为评分脚本编写者思考的方式配置系统**：能被机器验证的行为才是分数
- 韩国赛已公开评分脚本（本包内有），世界赛 Module A/B 的评分脚本也已在手——**把评分脚本当学习材料读一遍，胜过看十篇教程**

### 3.4 时间管理（比赛现场）

- 每题先花 5 分钟通读，按"分数/耗时比"排序
- 先保底（把能拿的 60% 快速拿满），再冲细节
- 断网/环境炸了不要慌：模块化重做，先恢复关键路径
- 留 10% 时间做 checklist 自检（参照评分标准逐条过）
