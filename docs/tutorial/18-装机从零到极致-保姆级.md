# 第 18 章 · 装机从零到极致（保姆级）

> 装机不是"拧螺丝"，是**在一堆兼容性约束里做正确决策，然后一次点亮**。
> 这一章带你从"分不清主板和显卡"，走到"能独立完成选件 → 组装 → 装系统 → 烤机 → 排障"的全流程。
> 学完你还能：看穿商家的套餐套路、判断一台机器的问题出在哪、给同学和朋友装机不翻车。
> **预计学习时间：2 周**（理论 3 天 + 反复看装机实录 3 天 + 在"全网资源库→装机区"跟练 + 有条件者实操 1 台）。

## 18.1 先建立整机世界观（10 分钟看懂一台电脑）

### 18.1.1 电脑 = 一座城市

| 部件 | 城市里的角色 | 干活的时候 | 它弱了会怎样 |
|---|---|---|---|
| CPU | 市长办公室 | 处理一切计算和调度 | 全局都慢、卡顿 |
| 内存 | 办公桌桌面 | 摊开正在处理的东西 | 多开几个程序就卡 |
| 硬盘（SSD） | 档案室+存取窗口 | 存放所有文件 | 开机慢、加载慢、软件卡 |
| 显卡 | 美术+特效团队 | 画面渲染、AI 计算 | 游戏掉帧、渲染慢 |
| 主板 | 道路网+市政大厅 | 连接一切、分配电力通讯 | 插不上、跑不满、不稳定 |
| 电源 | 发电站 | 把市电变成部件要的电 | 高负载黑屏重启，甚至烧件 |
| 散热器 | 空调系统 | 给 CPU/显卡降温 | 高温降频、蓝屏、寿命骤减 |
| 机箱 | 城市外壳+通风道 | 固定部件、组织风道 | 装不下、闷罐高温 |

**木桶效应**：短板决定体验。i9 + 老机械硬盘 = 开机 3 分钟；32G 内存 + 亮机卡 = 游戏 10 帧。**平衡比堆料重要。**

### 18.1.2 八大件清单（购物车核对表）

```
① CPU         ② 主板        ③ 内存条 ×1~4
④ 固态硬盘     ⑤ 显卡        ⑥ 电源
⑦ CPU散热器    ⑧ 机箱
（外设另配：显示器 / 键盘 / 鼠标 / 音箱）
```

### 18.1.3 台式机 vs 笔记本 vs 迷你主机

| | 台式机 | 笔记本 | 迷你主机 |
|---|---|---|---|
| 性价比 | **最高**（同价性能最强） | 低 | 中 |
| 升级 | 随便换 | 基本不能 | 内存/硬盘可以 |
| 便携 | 不能 | 最强 | 可以 |
| 散热/性能释放 | 强 | 受限于散热 | 中 |
| 适合 | 游戏/生产力/学习主机 | 学生党移动需求 | 办公/客厅/软路由 |

> 学生党预算有限时，**台式机 + 二手轻薄本**往往比一台全能本更划算。学校机房学习则完全不需要自购。

## 18.2 八大件深度认识（看懂参数=不被坑）

### 18.2.1 CPU（中央处理器）

**要看的 5 个参数**：

| 参数 | 含义 | 怎么看 |
|---|---|---|
| 核心/线程 | 同时干活的"人手" | 4核8线程日常够，6核12线程起步打游戏，8核+生产力 |
| 频率 | 干活速度（GHz） | 看"单核睿频"（游戏敏感）+ "全核频率" |
| 缓存 | CPU 自带的小仓库（L2/L3） | 越大越好，游戏 CPU 追求大 L3 |
| 平台/插槽 | 能不能插上主板 | Intel：LGA1700 / LGA1851；AMD：AM4 / AM5 |
| 功耗（TDP） | 发热和吃电 | 决定散热器和电源怎么选 |

**常见后缀**（Intel）：`K`=可超频、`F`=无核显、`KF`=无核显可超频、`T`=低功耗、无后缀=标准。例：i5-14600KF。
**AMD**：`X`=高性能版、`G`=带核显、`X3D`=大缓存游戏神U、无后缀=标准。例：R7 7800X3D。

**盒装 vs 散片**：盒装官方质保、自带散热器（高端款不带）；散片便宜但质保渠道不同（多为店保）。**买散片认准靠谱店铺，且注意"QS/ES 版"（工程样品）千万别买**——参数好看但不稳定、无质保。

**核显**：不带 F 的 Intel 和多数 AMD 带核显，够日常办公 + 硬解视频；**独立显卡与核显可以同时存在**（显示器插哪块用哪块，插主板口=用核显）。

### 18.2.2 主板（一切的连接底座）

**芯片组（决定功能上限）**：

| 档次 | Intel 例 | AMD 例 | 适合 |
|---|---|---|---|
| 入门 | H610 / B760 | A620 / B650 | 不折腾、够用就好 |
| 主流 | B760 / B860 | B650 / B850 | **大多数人的选择**（供电够、接口够） |
| 高端 | Z790 / Z890 | X670E / X870 | 超频、插满扩展 |

**关键接口（对照主板说明书看）**：
- **CPU 插座**：必须与 CPU 插槽完全一致（LGA1700 ≠ LGA1851，AM5 ≠ AM4）——这是装机第一兼容红线。
- **内存插槽**：DDR4 和 DDR5 物理不通用，插错硬插会坏。
- **M.2 插槽**：装 NVMe 固态，注意是 PCIe 3.0/4.0/5.0 × 几通道，**CPU 直连的 M.2 通常最快**。
- **SATA 接口**：接 2.5" SSD、机械硬盘。
- **PCIe ×16**：插显卡（注意是 4.0 还是 5.0 ×16）。
- **供电接口**：24pin（主板）、8pin/4+4pin（CPU）——**电源对应线材别插错**（CPU 8pin ≠ 显卡 8pin，插反会烧！）。
- **前面板针脚 F_PANEL**：开机键、重启键、指示灯的细针（后文详讲）。
- **后置 IO**：USB 数量/版本（看颜色和标注：蓝色 USB3、红色 USB3.2 Gen2 等）、HDMI/DP 视频输出（用核显时用）、网口（2.5G 渐成主流）、音频口。

**选购原则**：供电相数看评测（不超频 B 系列足够）→ 接口够用（M.2 至少 2 个、USB 够多）→ 品牌与 BIOS 口碑（华硕/微星/技嘉/华擎等）。**主板不影响性能上限，只影响"能不能稳定发挥 + 将来能不能扩"。**

### 18.2.3 内存（RAM）

| 参数 | 说明 | 建议 |
|---|---|---|
| 代数 | DDR4 / DDR5（**与主板绑定，不可混用**） | 新装机直接 DDR5 |
| 容量 | 8G / 16G / 32G / 64G | 办公 16G 起；游戏/多开 32G；生产 64G+ |
| 频率 | 如 6000MHz | DDR5 上 6000 左右是甜点 |
| 时序 | 如 CL30 | 同频下 CL 越小越好 |
| 通道 | 单/双通道 | **两条组双通道，性能差距可达 20%+** |

**双通道法则**：两条内存插主板 2、4 槽（离 CPU 第二近和第四近），具体看主板标注（DIMM_A2/B2）。四条插满可能降频，看主板 QVL 兼容列表。

**XMP/EXPO**：内存的"官方超频档案"，**默认不开**，进 BIOS 一键打开才能跑到标称频率（否则按 4800 保守频率跑）。

### 18.2.4 硬盘（速度与容量的家）

| 类型 | 接口 | 顺序速度 | 用途 |
|---|---|---|---|
| NVMe SSD | M.2 | 3000-14000MB/s | **系统盘首选** |
| SATA SSD | 2.5" | ~550MB/s | 副盘、老机升级 |
| HDD 机械 | 3.5" | 100-280MB/s | 仓库盘（存视频/备份） |

**看穿的参数**：
- **颗粒**：TLC 主流够用，QLC 尽量避开系统盘（一旦 SLC 缓存写满，速度掉到 100MB/s 以下）。
- **DRAM 缓存**：有独立缓存的盘性能更稳（看评测，别只看广告"高速"）。
- **缓外速度 / 温度**：好盘缓外仍 1000MB/s+；便宜的盘缓外掉到 U 盘水平。PCIe 4.0 盘注意加散热片。
- 品牌参考：三星/致态/西数/铠侠/英睿达等，看具体型号评测（同品牌的不同型号天差地别）。

**容量建议**：系统盘 1TB 起步（512G 很快满），仓库盘按需 2-4TB HDD。

### 18.2.5 显卡（GPU）

**型号解读**（以 NVIDIA 为例）：RTX 4070 Ti SUPER → 40=代，70=档位（60/70/80/90 越高越强），Ti/SUPER=增强版。AMD：RX 7800 XT 类似逻辑。

**关键点**：
- **显存**：容量（8G/12G/16G+）+ 位宽。2K 游戏建议 12G+，4K 游戏/AI 建议 16G+。
- **功耗**：直接决定电源功率（后文算）。中高端卡 200-450W。
- **长度**：35cm 级大卡**先量机箱限长**！
- **供电接口**：8pin ×1/2/3 或新 12V-2×6（12VHPWR 改良版）——电源必须带对应线，转接线慎用。
- **公版/非公**：非公=各家自己的散热和频率设计，看评测选（散热规模、噪音、售后）。
- **矿卡鉴别**：低于市场价太多的"仅拆封/女士自用"卡要警惕；到手查 GPU-Z 参数、烤机看温度与稳定性、看 PCB 有无返修痕迹。

**不玩游戏还要显卡吗**：剪视频/AI/多屏需要；纯办公核显足够（还能省几百瓦功耗）。

### 18.2.6 电源（整机的心脏，最不能省）

**功率估算公式**：
```
整机推荐电源功率 ≈ CPU 满载功耗 + 显卡满载功耗 + 100W(主板/硬盘/风扇余量) + 30% 冗余
例：i5-14600KF(~180W) + RTX 4070(~200W) + 100W = 480W → 选 650W 电源（留余量）
```

**要看的**：
- **80PLUS 认证**：白牌→铜→金→白金（转换效率，越高越省电，也侧面反映用料）。
- **模组**：全模组（只插要用的线，理线优雅）；直出线（便宜）。
- **单路+12V**：大功率单路比多路省心。
- **品牌**：海韵/振华/台达/长城/艾澎/美商海盗船等，看具体型号评测（**电源是"一分钱一分货"最明显的部件**）。
- **危险信号**：杂牌"额定 800W"实测不如正规 500W；电源烧毁常连带主板显卡一起走。

### 18.2.7 散热器

| | 风冷 | 一体式水冷（AIO） |
|---|---|---|
| 原理 | 塔体+风扇导热 | 冷头+水管+冷排 |
| 价格 | 50-400 元 | 300-1500 元 |
| 可靠性 | **极高**（就一个风扇会坏） | 有泵和漏液风险（概率低） |
| 性能上限 | 中高端够 | 高端/超大机箱更强 |
| 建议 | **大多数人的选择**（百元级双塔压 i5/R5 足够） | i9/R9 或喜欢颜值/小机箱时 |

- 高度限制：机箱说明书的"CPU 散热器限高"（如 160mm）必须 ≥ 散热器高度。
- 硅脂：薄薄一层/中间一点即可，**不是越多越好**；装好后别没事拆开看。
- 原装散热器（盒装自带）：能用，但吵、温度高，预算允许换百元风冷。

### 18.2.8 机箱

选机箱 = 选**尺寸 + 风道 + 颜值**：

| 板型 | 尺寸 | 说明 |
|---|---|---|
| ATX 中塔 | 最常见 | 散热好、装起来舒服 |
| M-ATX | 紧凑一点 | 性价比高、主流 |
| ITX | 最小 | 装起来精（受）致（罪），限制多 |

**核对三围**：显卡限长、散热限高、电源限长（ATX/SFX）。**风道**：前进后出/下进上出，风扇别全往外吹（会进灰+乱流）。追求静音可少装风扇+调曲线。

## 18.3 兼容性法则（装机不翻车核心课）

装机的本质就一句话：**每个接口都对上，每个尺寸都装得下，每个功率都供电足够。**

| 检查项 | 规则 | 翻车后果 |
|---|---|---|
| ① CPU ↔ 主板 | 插槽代数一致（LGA1700/1851/AM5…） | 插不上，硬插针脚弯 |
| ② 内存 ↔ 主板 | DDR4/DDR5 与主板一致 | 插不进，硬插坏条 |
| ③ 电源功率 | 按公式留 30% 余量 | 高负载黑屏重启 |
| ④ 电源线材 | CPU 8pin、显卡 8pin 数量≥需求 | 少一根没法点亮 |
| ⑤ 显卡长度 ↔ 机箱 | 限长 ≥ 显卡长度 | 装不进，锯机箱（误） |
| ⑥ 散热高度 ↔ 机箱 | 限高 ≥ 散热高度 | 侧板盖不上 |
| ⑦ M.2 长度 | 2280 为主流，看主板支持 | 装不上/翘起 |
| ⑧ BIOS 版本 | 新 CPU 装老主板可能要刷 BIOS | 点不亮，需 U 盘免 U 刷 BIOS |

> 自查习惯：**下单前把八大件写成一张表，把上表 ①-⑧ 逐项打勾**。这一步花 10 分钟，省一整天。

## 18.4 选购策略（钱花在刀刃上）

### 18.4.1 按用途选路线

| 用途 | CPU | 内存 | 硬盘 | 显卡 | 总价位参考 |
|---|---|---|---|---|---|
| 办公/网课 | 入门 4-6 核 | 16G | 512G-1T | 核显 | 2-3k |
| 学生全能 | 中端 6 核 | 16-32G | 1T | 中端独显 | 4-6k |
| 游戏主力 | 高频 6-8 核 | 32G | 1T | 中高端 | 6-10k |
| 剪辑/建模/AI | 8 核+ | 32-64G | 1T+仓库盘 | 大显存 | 10k+ |

### 18.4.2 预算分配心法（参考比例）

```
CPU :    主板 :  内存 :  硬盘 :  显卡 :  电源+散热+机箱
约 20% :  12%  :  8%  :  8%  : 38%  :  14%（游戏向）
生产力向：显卡比例降低，CPU/内存比例提高
```

### 18.4.3 避坑清单（血泪版）

- **整机陷阱**："i7 级"（其实是老 i7）、"多大显存"（杂牌 4G 亮机卡）、"高速固态"（QLC 无缓存）——**只认具体型号！**
- **洋垃圾**：X99 平台上拆机 Xeon（核心多但单核差、无质保）——除非明确折腾，别碰。
- **二手交易**：当面验机（CPU-Z/GPU-Z/硬盘 SMART/烤机 20 分钟）；走平台验货宝；"太便宜"= 危险信号。
- **购买时机**：新品首发贵、618/双11 有活动价；内存硬盘价格波动大（涨价周期别硬买）。
- **渠道**：京东自营/天猫旗舰/品牌代理 = 稳妥；拼夕夕百亿补贴要辨店铺；闲鱼拼运气。

## 18.5 装机全流程（12 步·文字图解）

> ⚠️ 全程铁律：**断电操作、防静电（摸金属/戴手环）、轻拿轻放、别用蛮力、螺丝别掉进机箱**。

### 步骤 1｜准备
- 工具：十字螺丝刀（带磁性最佳）、扎带、剪刀、硅脂（散热器常自带）、小手电。
- 桌面铺软垫（主板包装盒最合适），**站在水泥地/摸过暖气片后再动手**（防静电）。
- 所有部件先在桌上摆开，**说明书/主板手册放旁边**。

### 步骤 2｜开箱检查
- 核对型号与订单一致；看主板针脚有无弯曲（Intel 主板针脚在主板上，AMD 在 CPU 上）。
- 拍照留念（保修凭证 + 万一装错好对照）。

### 步骤 3｜安装 CPU
```
① 打开主板 CPU 插座压杆/盖子
② 看方向标记：CPU 一角有金色三角 ▲，插座对应角有三角
③ 放平轻放（对不上=方向错了，别按！）
④ 压下压杆（稍用力，正常有卡顿感）
```
> 针脚歪了：**别自己挑**，送保修点处理。AMD AM5 是 LGA，同样轻放。

### 步骤 4｜安装散热器
- **风冷**：先装背板/扣具 → 涂硅脂（黄豆大）→ 压上塔体 → **对角线交替上紧**螺丝 → 插风扇到 CPU_FAN 针（4 针）。
- **水冷**：冷排先装到机箱（顶部/前置），冷头后装；泵线插 AIO_PUMP 或 CPU_FAN。

### 步骤 5｜安装内存
- 掰开插槽卡扣 → 对准防呆缺口 → **两端同时下压到"咔哒"**。
- 两条 → 插第 2、4 槽（看主板标注，优先 A2/B2）。

### 步骤 6｜安装 M.2 固态
- 拧下散热马甲螺丝 → 硬盘金手指对准插槽（约 30° 斜插入到底）→ 尾部螺丝固定 → 装回马甲（**先撕掉马甲上的保护膜！**）。

### 步骤 7｜主板进机箱
- 先拧机箱铜柱（对照主板孔位，**数清楚，多拧的铜柱会顶坏主板背面**）。
- 装上主板 IO 挡板（很多机箱原生自带）→ 放主板 → 拧螺丝（先全部对上再逐个收紧，**别一开始就拧死**）。

### 步骤 8｜安装电源
- 风扇朝下（下置机箱，进风口有防尘网）→ 从机箱后部推入 → 拧四颗螺丝。
- 线材规划：先接 24pin 和 CPU 8pin（**这两根最难穿，先走好**）。

### 步骤 9｜安装显卡
- 拆机箱对应槽位的挡板 → 打开 PCIe 卡扣 → 显卡金手指对准插到底（听到卡扣扣上）→ 拧螺丝固定。
- 接供电线（8pin/12VHPWR，**听到卡扣声**）。**重量大的卡装防坠支架**。

### 步骤 10｜接线（重点！逐根核对）
```
【电源出来的线】
24pin ──→ 主板大宽口（唯一能插的，防呆）
CPU 8pin/4+4pin ──→ 主板左上角（CPU_PWR，别和显卡线混！）
显卡 8pin/12VHPWR ──→ 显卡供电口（有几口接几口）
SATA 供电 ──→ SSD/HDD（如用）
【机箱出来的线】
F_PANEL 前面板 ──→ 主板右下角小针脚：
  PWR_SW（开机）  = 两针，不分正负
  RESET_SW（重启）= 两针，不分正负
  PWR_LED（电源灯）= 分正负（+ 在左或按标注）
  HDD_LED（硬盘灯）= 分正负
  USB 3.0 大蓝口 ──→ 主板 F_USB3（防呆，别硬插）
  USB 2.0 9 针 ──→ F_USB
  HD_AUDIO ──→ 主板音频针（JAUD1 之类）
【风扇线】
CPU 风扇 → CPU_FAN（必须！否则报 CPU Fan Error）
机箱风扇 → SYS_FAN / CHA_FAN
```

### 步骤 11｜理线
- 用扎带把线捆成束走背线仓；**别把线卡在风扇里**。

### 步骤 12｜首次点亮（激动时刻）
```
接好电源线 → 显示器线接【显卡】（有独显别插主板！）→ 按开机键
观察：风扇转？主板灯亮？显示器出 BIOS 画面？
```
**点不亮排查树**：
1. 电源开关（机箱后部 I/O 开关）= I 位置？
2. 电源线/插排有电吗？
3. 内存重插（换槽试单条）
4. 显卡重插、供电线到位？
5. F_PANEL 接对了吗？
6. 散热器风扇插了 CPU_FAN 吗？
7. 还不行 → 最小系统法：只留 CPU+1 条内存+电源，逐个加回。

## 18.6 BIOS/UEFI 设置（点亮后第一站）

按 `Del`/`F2` 进入（开机画面有提示）。

| 设置项 | 作用 | 操作 |
|---|---|---|
| **XMP/EXPO** | 内存跑满标称频率 | 一键开启（找不到就翻"超频"页） |
| 启动顺序 Boot Order | 从 U 盘启动装系统 | 把 USB 调到第一 |
| 风扇曲线 | 静音/散热平衡 | 调 Fan Curve（AUTO 也行） |
| 安全启动 Secure Boot | Win11 要求 | 装 Win11 保持开启 |
| 虚拟化 VT-x/SVM | 跑虚拟机/WSL2 需要 | 保持开启 |
| 更新 BIOS | 新 CPU 兼容/修复 bug | 官网下载 → U 盘 → BIOS 内 EZ Flash |

> 装完系统后回来把 XMP 打开，是最容易被忘的一步——**忘了=内存白买高频率**。

## 18.7 装系统（Windows 11 官方流程 + Linux 双系统）

### 18.7.1 制作启动盘（Ventoy 神器）

1. 官网下载 Ventoy → 插入 U 盘（8G+，会格式化）→ 一键安装。
2. 把 **微软官网下载的 Win11 ISO 直接拷贝进 U 盘**（不用解压不用工具）。
3. 想装 Linux？再拷个 Ubuntu/Deepin ISO 进去，**一个 U 盘装所有系统**。

### 18.7.2 Windows 11 安装

```
① U 盘插机箱后置 USB → BIOS 里选 U 盘启动（或 F8 快速启动菜单）
② 安装界面：语言 → 现在安装 → "我没有产品密钥"（可后激活）
③ 版本选 专业版/家庭版 → 自定义安装
④ 分区：选未分配空间 → 新建 → 系统会自动建 ESP/MSR/主分区
   （想手动了解一下：ESP ~100-300M 引导区 + MSR 16M + C 盘剩余）
⑤ 安装 → 重启（拔 U 盘）→ 开箱设置（跳过联网：Shift+F10 → oobe\bypassnro）
```

### 18.7.3 装完系统三件事

1. **驱动**：Windows 更新自动装大部分；显卡驱动去 NVIDIA/AMD 官网装最新（或官网工具）。
2. **激活**：正版密钥 or 学校/公司授权渠道。
3. **基础软件**：浏览器、压缩、解压、办公套件、图吧工具箱级别的检测工具（见资源库工具箱）。

### 18.7.4 Linux 双系统要点

- Win11 装好后再装 Linux（Linux 引导器能识别 Windows）。
- 分区：Linux 建议单独 50-100G+ 空间，swap 按需（内存 ≥16G 可小）。
- 启动项用 GRUB 管理；想默认进 Windows 可调 GRUB 默认项（`grub-customizer` 等）。

## 18.8 验机与烤机（新机必做）

| 项目 | 工具 | 标准 |
|---|---|---|
| CPU 稳定性/温度 | OCCT / AIDA64 FPU | 满载 15 分钟不黑不蓝；温度 <90℃ 可接受，>100℃ 要查散热 |
| 内存 | MemTest86（U 盘启动） | 一轮 0 错误；XMP 开了再测一轮 |
| 显卡 | FurMark / 3DMark | 温度稳定、无花屏；功耗频率符合评测 |
| 硬盘 | CrystalDiskInfo / CrystalDiskMark | SMART 正常；速度达到型号标称 |
| 整机 | 3DMark / 游戏实测 | 分数对比同配置公开数据 |

> 新机流程：点亮 → BIOS 开 XMP → 装系统 → 驱动 → **烤机 1 小时** → 通过=交付。
> **"烤机"的意义：把 7 天内会暴露的硬件缺陷逼出来**，此时还能免费换新。

## 18.9 故障排查速查表

| 症状 | 常见原因 | 排查顺序 |
|---|---|---|
| 按开机键没反应 | 电源开关/插排/跳线 | 电源 IO 开关 → 插排 → F_PANEL → 电源短接测试 |
| 风扇转但黑屏 | 内存/显卡/显示器线 | 内存重插换槽 → 显示器线接显卡 → 换线 |
| 反复重启 | 电源不足/内存不稳/温度 | 关 XMP → 测电源 → 查温度 |
| 蓝屏（BSOD） | 驱动/内存/系统 | 记错误码 → 更新驱动 → 内存测试 |
| 玩游戏黑屏重启 | 电源峰值不够/显卡供电 | 换更大电源/检查供电线插紧 |
| 温度高声音大 | 散热器没装好/硅脂干了/风道差 | 重装散热 → 换硅脂 → 理风道 |
| 开机进 BIOS 不进系统 | 启动顺序/硬盘掉盘 | 检查硬盘识别 → 启动顺序 → 引导修复 |
| 用一会儿卡死 | 硬盘掉速/内存错误/过热 | SMART 检查 → 内存测试 → 温度监控 |

> 排查心法：**先软件后硬件、先简单后复杂、先替换后深入**。每次只动一个变量。

## 18.10 升级与维护（让机器多活 3 年）

- **清灰**：每 6-12 个月（吹气球/软刷/压缩空气），断电操作；笔记本更要勤。
- **换硅脂**：2-3 年一次（温度明显高了再换也行），拆装散热器时顺手。
- **加内存/换硬盘**：最划算的升级；换系统盘用克隆工具（如 DiskGenius/傲梅）免重装。
- **BIOS 更新**：不是必需，除非新 CPU 兼容/修复安全问题。
- **系统维护**：C 盘留 20% 以上空闲；软件装 D 盘习惯；定期备份重要数据（3-2-1 原则）。

## 18.11 特殊形态：笔记本 / 迷你主机 / 二手

- **笔记本**：不可组装，选机看——CPU 型号后缀（H 高性能/U 低压）、屏幕（高刷+高色域）、散热规模（双风扇双热管+）、接口。**同样型号不同配置差价大，看具体配置单。**
- **迷你主机**：核显办公神器（N100/7840HS 类），能挂显示器背后；注意散热与扩展口。
- **二手**：值得买的情形=预算紧张+懂验机；验机三件套（CPU-Z 看参数、CrystalDiskInfo 看通电时间、烤机看稳定性）。
