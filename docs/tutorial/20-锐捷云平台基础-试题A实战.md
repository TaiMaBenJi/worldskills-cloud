# 第20章 · 锐捷云平台基础 —— 试题 A 实战

> **适用**：B7 实训中心机房管理 ·《锐捷云平台基础》试题 A（实操考试）
> **一句话目标**：在锐捷云平台走通「制作镜像 → 新建教室 → 师生互动验证」，**参数一个不错、后台 0 报错**，拿满 100 分。
> **模拟自测**：读完本章，去「考试中心 → 章节测验 → 第20章 · 锐捷云平台基础」做 15 题模拟（自动判分）。

---

## 0. 先看懂规则（判分结构）

| 环节 | 分值 | 要点 |
|---|---|---|
| 镜像制作 | **60 分** | 名称、系统版本、4/4/60、账户 adminjf、装 VS、无数据盘 |
| 教室要求 | **20 分** | 教室名、教师机主机名、座位名前缀 |
| 机房 IP 部署 | **10 分** | 教师端 .100 / 学生端 .101 起 |
| 师生信息交互 | **10 分** | 文件分发 + 屏幕广播，两项都要通 |

**三条铁的规则**

1. **报错最贵**：锐捷云后台报错 ≥2 次，每次 **-10 分**。稳，比快重要。
2. **下发不计时**：镜像批量下发学生机的时间**不算**考试时间——不用抢，但更不许中途强操作。
3. **最终解释权归统计员**（尹占熙 / 丁秋林 / 鞠雨航）：拿不准 → 先问，**问不扣分，报错才扣分**。

## 2. 阶段一 · 制作镜像（60 分）

1. 教师账号登录**锐捷云管理平台** → 进「镜像管理」→ 新建 / 制作镜像。
2. 按速查卡填：名称 = 汉语姓名；系统 = Windows 10 22H2 专业版；处理器 4、内存 4G、系统盘 60G；账户 **adminjf**。
   🎯 *为什么强调"不超标"：试卷原文写明"做到资源合理分配不超标"——多给配置同样算错。*
3. 打开镜像控制台（母机），用 **adminjf** 登录 → 安装 **VS** → 按考题要求把数据 / 文件 / 程序部署到位。
4. 关机 → 提交 / 完成镜像 → 等状态变「可用」。
   🚨 提交过程中**不强关、不重复提交**——这里是后台报错高发区。

## 3. 阶段二 · 新建教室（20 + 10 分）

1. 「教室管理」→ 新增教室：教室名称 = 汉语姓名；选择刚做好的镜像；座位按考场实际（教师位 1 个）。
2. **网络 / IP（10 分）**：网段用考场资源池给出的（前三段别动）；**教师端第 4 位 = 100**；**学生端 101 起逐台 +1**。
   🎯 *"学生端：教师+1 起" = 第 1 台学生 .101、第 2 台 .102……不是都用 .101。*
3. **命名**：教师机主机名 **gyjsjs**；座位名前缀 **gyjszw-**（半角连字符，别漏也别用中文破折号）。
4. **桌面策略**：教师端无数据盘；学生端无数据盘 + 无个性化（还原模式）。
5. 保存 → 执行「**镜像批量下发**学生机」→ 等全部「已完成」。
   ⏳ 下发不计入考试时间；但**下发没完成前，不碰终端、不关机、不重启**。

## 4. 阶段三 · 师生互动验证（10 分）

1. 开机**教师机 + 至少 2 台学生机**，核对：学生机 IP = …101 / …102，教师机主机名 gyjsjs。
2. 打开教学互动软件，做两项：
   - **文件分发**：发个小文件（txt 即可）→ 学生机收到并打开 ✔
   - **屏幕广播**：开启广播 → 学生机画面同步显示 ✔
3. 两项都通过 → 举手请统计员验收。

## 5. 扣分雷区（背下来）

- ❌ 平台在转圈 / 进度条没走完就点下一步、刷新页面、关终端
- ❌ 多给内存、加数据盘、装无关软件（资源超标）
- ❌ 下发 / 部署途中强操作终端
- ❌ 没做出可用镜像就先建教室（必报错）
- ✅ 拿不准 → 问统计员；✅ 每一步等状态变绿再走
