# 世界技能大赛全技能精通库

面向世界技能大赛全部赛项的中文自学精通库：每个赛项一篇深度总纲，讲清项目是什么、怎么比、核心能力域、从零到赛场的精通路线、训练体系、自测清单与避坑指南。

赛项按世界技能组织的六大领域归类。竞赛项目与标准以世界技能组织当届官方文件为准，本库为独立整理的学习框架，随当届信息持续补充。

## 使用方法

1. 先读自己赛项的总纲，建立全景与路线感。
2. 按总纲中的阶段路线制定计划，配合自测清单每周核验。
3. 云计算赛项有完整的深度内容：20 章保姆级教程、62 集视频课、全中文赛题库、离线 App，见仓库首页。
