## 实操环境约定

实操题默认在 **Ubuntu 22.04 练习机**（WSL2）上完成，评分脚本以 root 运行：

```bash
# 例：网络系统管理赛题评分
sudo bash multiskill/03-网络系统管理/grad_netsys.sh

# 云计算 WSL 训练场（先按 cloud-lab/mission.md 部署迷你高可用平台）
sudo bash multiskill/cloud-lab/build_lb.sh
```

> ⚠️ 文中部分命令带有作者机器的本地路径（如 `/mnt/d/Desktop/世界技能大赛云计算`），clone 后请替换成你自己的仓库路径。
> 网络系统管理赛题做砸可一键清场重做：`sudo bash multiskill/03-网络系统管理/重置环境.sh`。
