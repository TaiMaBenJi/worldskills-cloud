## 任务 1 · DNS（bind9）

`/etc/bind/named.conf.local` 追加：

```
zone "wsnet.local" {
    type master;
    file "/etc/bind/db.wsnet.local";
};
zone "100.168.192.in-addr.arpa" {
    type master;
    file "/etc/bind/db.192.168.100";
};
```

`/etc/bind/db.wsnet.local`：

```
$TTL    604800
@       IN      SOA     ns1.wsnet.local. admin.wsnet.local. (
                              2 604800 86400 2419200 604800 )
@       IN      NS      ns1.wsnet.local.
ns1     IN      A       192.168.100.1
www     IN      A       192.168.100.10
app     IN      CNAME   www
```

`/etc/bind/db.192.168.100`：

```
$TTL    604800
@       IN      SOA     ns1.wsnet.local. admin.wsnet.local. (
                              2 604800 86400 2419200 604800 )
@       IN      NS      ns1.wsnet.local.
10      IN      PTR     www.wsnet.local.
```

生效：`named-checkconf` → `systemctl restart named` → `dig @127.0.0.1 ...` 验证。

## 任务 2 · Samba

`/etc/samba/smb.conf`：在 `[global]` 段加一行 `map to guest = Bad User`，文末追加：

```
[wsdata]
   path = /srv/wsdata
   browseable = yes
   guest ok = yes
   read only = yes
```

生效：`mkdir -p /srv/wsdata` → `systemctl restart smbd nmbd` → `smbclient -L //127.0.0.1 -N` 验证。

## 任务 3 · NFS

```
mkdir -p /srv/nfs/ws
chown nobody:nogroup /srv/nfs/ws
echo '/srv/nfs/ws 127.0.0.1(rw,sync,no_subtree_check)' >> /etc/exports
exportfs -ra
mount -t nfs4 127.0.0.1:/srv/nfs/ws /mnt/nfs-test
echo ok > /mnt/nfs-test/probe.txt
```

> `chown nobody:nogroup` 是关键：默认 root_squash 会把客户端 root 映射成 nobody，目录属主不对就会写不进。

## 任务 4 · vsftpd

`/etc/vsftpd.conf` 确保：

```
local_enable=YES
write_enable=YES        # 默认被 # 注释，必须打开
```

上传验证：

```
echo "test" > /tmp/ws-ftp-upload.txt
curl -T /tmp/ws-ftp-upload.txt --user student:123456 ftp://127.0.0.1/
```

## 任务 5 · systemd 定时器

`/usr/local/bin/ws-clean.sh`（chmod +x）：

```bash
#!/bin/bash
mkdir -p /var/lib/ws-clean
date > /var/lib/ws-clean/last-run
```

`/etc/systemd/system/ws-clean.service`：

```
[Unit]
Description=WSNET periodic clean task
[Service]
Type=oneshot
ExecStart=/usr/local/bin/ws-clean.sh
```

`/etc/systemd/system/ws-clean.timer`：

```
[Unit]
Description=Run ws-clean every 10 minutes
[Timer]
OnCalendar=*:0/10
Persistent=true
[Install]
WantedBy=timers.target
```

生效：`systemctl daemon-reload` → `systemctl enable --now ws-clean.timer` → `systemctl start ws-clean.service`。
