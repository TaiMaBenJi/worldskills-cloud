## P1 · 单模光链路预算（基础）

某园区链路：单模光缆 **8km**，工作波长 **1310nm**（衰减按 0.35 dB/km）；链路上有 **3 个熔接点**（每个按 0.3dB）、**2 个活动连接器**（每个按 0.75dB）；光模块发射功率 −3dBm，接收灵敏度 −24dBm。

求：允许损耗、实际总损耗、功率余量，并判断是否达标（余量 ≥3dB）。

## P2 · 换波长重算

上题同一链路改用 **1550nm** 窗口（衰减按 0.20 dB/km），其余不变。求新余量，并说明 1550 比 1310 在光缆段上少损耗多少 dB。

## P3 · 多模楼内主干

楼内主干：OM3 多模 **550m**，850nm（衰减 3.5 dB/km）；2 个连接器（0.75dB/个）、1 个熔接点（0.3dB）；模块发射 −2.5dBm，灵敏度 −15dBm。求余量并判断达标。

## P4 · 不达标诊断（反例，重点）

某链路：单模 **60km**，1310nm（0.35 dB/km）；2 个连接器（0.75）、4 个熔接点（0.3）；模块发射 0dBm、灵敏度 −20dBm。

a) 求余量，判断能否开通。
b) 不达标的话，给出**至少一个**可行的整改方案并验证（提示：换工作窗口重算）。

## P5 · NVP 现场校准

从整箱线抽出一段线，**卷尺实测 30m**；认证仪 NVP 设为 69% 时，仪器读数 **28.5m**。求校准后的 NVP（保留一位小数），并说明 NVP 对长度测量的影响方向。

## P6 · 铜缆长度合规判断

某水平布线：配线架→插座永久链路 **82m**；两端跳线分别 5m 和 4m。

a) 永久链路合规吗？
b) 信道长度是多少？合规吗？
c) 跳线总长符合"共约 10m"的惯例吗？

## ✅ 参考答案（做完再看！）

**P1**　允许 = −3 −(−24) = **21dB**；实际 = 8×0.35 + 3×0.3 + 2×0.75 = 2.8+0.9+1.5 = **5.2dB**；
余量 = 21 − 5.2 = **15.8dB** ≥3 ✅ 达标（余量非常充裕）。

**P2**　实际 = 8×0.20 + 0.9 + 1.5 = 1.6+2.4 = **4.0dB**；余量 = 21 − 4.0 = **17.0dB** ✅。
光缆段少损耗 2.8 − 1.6 = **1.2dB**（1550nm 窗口衰减更低，长距离常用）。

**P3**　允许 = −2.5 −(−15) = **12.5dB**；实际 = 0.55×3.5 + 2×0.75 + 0.3 = 1.93+1.5+0.3 = **3.73dB**；
余量 = 12.5 − 3.73 = **8.77dB** ≥3 ✅。

**P4**　a) 允许 = 0 −(−20) = 20dB；实际 = 60×0.35 + 1.5 + 1.2 = 21+2.7 = **23.7dB**；
余量 = 20 − 23.7 = **−3.7dB** < 0，**链路不通**（连 0 余量都不到，必死）。
b) 整改：改用 1550nm 窗口 → 实际 = 60×0.20 + 2.7 = 14.7dB → 余量 = 20−14.7 = **+5.3dB** ✅（也可换高发射功率模块/减少连接点，方案合理即可）。

**P5**　长度读数与 NVP 成正比：真实 NVP = 69 × 30 ÷ 28.5 ≈ **72.6%**。
方向：NVP 设得比真实值**大** → 读数偏**长**；设小了 → 读数偏短（比值关系，考试常设坑）。

**P6**　a) 82m ≤ 90m ✅；b) 信道 = 82+5+4 = **91m** ≤ 100m ✅；c) 跳线合计 9m ≈ 10m 惯例 ✅。
三项全合规——遇到"接近上限"的链路（91/100）仍要在报告中标注提示余量。
