# 🌐 网站设计与开发（Web Technologies）· 学习路线图

> 状态：**路线图已就绪，训练场待建设**。想开建时直接说"把网站训练场搭起来"。

## 赛项比什么（典型模块）

| 模块 | 内容 | 本地可练度 |
|------|------|:---:|
| 前端实现 | HTML5 语义化 / CSS3 布局（Flex/Grid）/ 响应式 | ✅✅ |
| 前端交互 | JavaScript DOM、表单校验、fetch | ✅✅ |
| 后端开发 | PHP / Node.js + MySQL 增删改查 | ✅✅ WSL 可练 |
| 全栈整合 | 按设计稿复刻网站 + 后台管理 + 数据库 | ✅✅ |
| 可访问性与规范 | W3C 校验、无障碍 | ✅ |

## 竞赛特点

按**设计稿复刻**（像素级）+ 按需求文档实现功能（登录/购物车/后台 CRUD），评分点非常细：布局还原度、语义化标签、响应式断点、表单校验提示等。

## 训练场规划（待建设清单）

1. **复刻任务卡**：给设计图 + 素材，限时复刻静态页 → 评分表自检（还原度/语义化/响应式）
2. **PHP+MySQL 任务卡**：新闻发布系统（列表/详情/后台登录/增删改查），grad.sh 数据库断言判分
3. **JS 闯关题**：表单校验/轮播/异步加载，逐关判分
4. **真题集**：历年世赛/国赛赛题整理
