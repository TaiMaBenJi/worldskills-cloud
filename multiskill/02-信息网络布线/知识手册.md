## 2. 综合布线系统架构（GB 50311-2016）

综合布线系统划分为 **7 个部分**：

```
工作区子系统 → 配线子系统（水平）→ 干线子系统（垂直）→ 建筑群子系统
                    设备间 · 进线间 · 管理（贯穿全系统）
```

| 子系统 | 一句话 | 典型构成 |
|--------|--------|----------|
| 工作区 | 信息插座到终端设备 | 跳线、信息模块、面板 |
| 配线（水平） | 楼层配线架（FD）到工作区插座 | 4 对双绞线，≤90m |
| 干线（垂直） | 设备间到各楼层配线间 | 大对数铜缆 / 光缆 |
| 建筑群 | 楼与楼之间 | 室外光缆 |
| 设备间 | 大楼核心机房 | 网络设备、总配线架 |
| 进线间 | 外部线缆引入 | 入口设施 |
| 管理 | 标识、文档、跳线管理 | 色标、标签、记录 |

> 记忆钩子：**水平 90 米，信道 100 米**（见 §3）。干线尽量走光，楼宇之间必走光。

## 3. 铜缆（双绞线）体系

### 3.1 类别速查（必背）

| 类别 | 带宽 | 支持速率 | 100m 信道 | 备注 |
|------|------|----------|:---:|------|
| Cat5e（超五类） | 100 MHz | 1 Gbps（1000BASE-T） | ✅ | 千兆入门 |
| Cat6（六类） | 250 MHz | 1 Gbps | ✅ | 10GBASE-T 只能跑 **37~55m** |
| Cat6A（超六类） | 500 MHz | 10 Gbps（10GBASE-T） | ✅ | 万兆到 100m 的性价比主流 |
| Cat7（七类） | 600 MHz | 10 Gbps | ✅ | 全屏蔽 S/FTP，接口 GG45/TERA（非 RJ45） |
| Cat8（八类） | 2000 MHz | 25 / 40 Gbps | ❌ 仅 **30m** | 机房短连接（服务器→交换机） |

> 记忆钩子：**6A 管万兆百米，8 类万兆三十米**。带宽翻着涨：100 → 250 → 500 → 600 → 2000 MHz。

### 3.2 链路模型：永久链路 vs 信道

```
[仪器]--测试跳线--\                        /--测试跳线--[仪器]   ← 信道 Channel（≤100m）
[配线架]===== 永久链路 Permanent Link（≤90m）=====[信息插座]
```

- **永久链路（PL）**：配线架 → 信息插座之间的固定布线，**≤90m**（GB 50311 / TIA-568）
- **信道（Channel）**：端到端含两端设备跳线，**≤100m**
- 跳线总长一般 ≤10m（工作区 5m + 设备间 5m）

### 3.3 线序：T568A / T568B（必背）

| 针脚 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|------|---|---|---|---|---|---|---|---|
| **T568A** | 白绿 | 绿 | 白橙 | 蓝 | 白蓝 | 橙 | 白棕 | 棕 |
| **T568B** | 白橙 | 橙 | 白绿 | 蓝 | 白蓝 | 绿 | 白棕 | 棕 |

- 两端同为 B（或同为 A）= **直通线**（现代设备全部用直通线）
- 两端一 A 一 B = **交叉线**（老设备对接才用，现已基本淘汰，万兆自协商 MDI/MDIX 自动翻转）
- 数据传输：百兆用 2 对（1-2、3-6）；**千兆及以上 4 对全用**
- 工程统一用 **T568B**（国内惯例）

### 3.4 屏蔽命名（ISO/IEC 11801 记法）

`x/yTP`：x = 总屏蔽层，y = 每线对屏蔽
- **U/UTP** = 无屏蔽（非屏蔽双绞线）
- **F/UTP** = 铝箔总屏蔽
- **SF/UTP** = 丝网+铝箔总屏蔽
- **S/FTP** = 丝网总屏蔽 + 每对铝箔屏蔽（Cat7/8 标配）

> 屏蔽系统必须做**等电位接地**，两端接地，否则屏蔽层反而变"天线"引入干扰。

## 4. 铜缆认证测试参数（Fluke 判读核心）

| 参数 | 全称 | 测什么 | 常见 FAIL 原因 |
|------|------|--------|----------------|
| **WIRE MAP** | 接线图 | 8 根线针脚对应关系 | 开路/短路/错对/反接/**串绕** |
| **LENGTH** | 长度 | 电学长度（TDR 原理） | 超 90m/100m；额定传输速率 NVP 设错会误报 |
| **插损 IL** | Insertion Loss（衰减） | 信号跑完全程衰掉多少 | 线太长、劣质线、超温运行 |
| **NEXT** | 近端串扰 | 发送对对相邻接收对的干扰（**测的是近端**） | 端接开绞过长（>13mm）、串绕 |
| **PS NEXT** | 综合近端串扰 | 3 对同时干扰 1 对的总和 | 同上 |
| **ACR-F**（原 ELFEXT） | 等效远端串扰 | 远端的串扰比 | 同类，远端开绞差 |
| **回损 RL** | Return Loss | 阻抗失配反射（100Ω 标称） | 线缆受压变形、接头阻抗不连续、跳线弯折 |
| **传播时延** | Propagation Delay | 信号跑 100m 的时间 | 一般不 FAIL，超长才超 |
| **时延偏差** | Delay Skew | 4 对线中最快与最慢的差 | **≤50ns**（信道）；劣质线绞距不合格 |
| **直流环路电阻** | DC Loop Resistance | 线对往返总电阻 | 线径不足（铜包铝假线必 FAIL） |

### 故障判读速记（判读专项必考）

- **串绕（Split Pair）**：两根不同对的线绞在一起，针脚序号看起来"对"但线对错了 → NEXT **惨烈 FAIL**，长距离完全不通。根源：剥皮后没按对分组。
- **反接（Reversed Pair）**：同一线对两端针脚互换（如 1↔2）。
- **错对（Crossed Pair）**：两个线对整体调换。
- **NEXT 在高频端 FAIL、低频过**：典型开绞过度破坏/接头质量差。
- **LENGTH 用 TDR 原理**：测的是"电学长度"，受 **NVP（额定传输速率，典型 ~69%）** 影响 —— NVP 设不准，长度就测不准（可现场校准：用已知长度线校 NVP）。

## 5. 光纤体系

### 5.1 单模 vs 多模（必背）

| | 多模 Multimode | 单模 Single-mode |
|---|---|---|
| 芯径 | 50/125 µm（OM3/OM4/OM5） | 9/125 µm（OS1/OS2） |
| 光源 | LED / VCSEL（850、1300nm） | 激光 LD（1310、1550nm） |
| 典型衰减@主用波长 | OM3 3.5 / OM4 3.0 dB/km @850nm | **0.35 dB/km @1310nm，0.20 dB/km @1550nm** |
| 色散 | 模间色散限制距离 | 色散小 → 距离远 |
| 应用 | 楼内主干（≤550m 为主） | 园区/城域、长距离 |
| 标识 | 橙色（OM3/4 常见水绿/Aqua）外皮 | 黄色外皮 |

**万兆典型距离**：10GBASE-SR → OM3 300m / OM4 400m；10GBASE-LR（单模）10km；40G/100G 用 MPO 多芯并行或 CWDM。

### 5.2 三种接续方式

| 方式 | 工艺 | 典型损耗 | 场景 |
|------|------|----------|------|
| **熔接** | 熔纤机电弧熔接 | **0.02~0.08 dB** | 主流，永久链路 |
| **冷接（机械接续）** | 冷接子+匹配液 | 0.1~0.3 dB | 快速抢修、入户 |
| **活动连接器** | FC/SC/LC/ST 研磨端面 | 单个成对 **≤0.75 dB**（TIA 上限），典型 0.3 | 设备端口、配线架 |

接头端面研磨等级：PC（物理接触）→ UPC（超 PC，回损 ≥50dB 单模）→ APC（8° 斜面，**绿色**，回损 ≥60dB，用于 CATV/高反射敏感系统；UPC 与 APC **不可混接**）。

### 5.3 光链路预算（计算专项核心公式）

```
允许损耗 A允许 = 发射功率 P发 − 接收灵敏度 P收          （dB）
实际损耗 A实际 = 光缆长 × 每km衰减
             + 连接器数 × 0.75   （按上限保守算，或题目给定值）
             + 熔接点数 × 0.3     （同上）
             + 其他（分路器/法兰等）
余量 M = A允许 − A实际        → 验收要求 M ≥ 2~3 dB（工程惯例取 3）
```

**例**：10km 单模，1310nm，衰减 0.35dB/km；2 个熔接点、2 个连接器；光模块 P发=0dBm、灵敏度=−18dBm。
A允许 = 0−(−18) = 18dB；A实际 = 10×0.35 + 2×0.3 + 2×0.75 = 3.5+0.6+1.5 = 5.6dB；**余量 = 12.4dB ≥ 3dB ✅**

## 6. 光纤测试与 OTDR 判读

### 6.1 两种测损耗方法

- **插入损耗法（OLTS）**：稳定光源 + 光功率计，两点测总损耗 —— **认证验收以它为准**（单向）
- **OTDR（光时域反射仪）**：发脉冲看背向散射，**定位事件位置与损耗** —— 诊断/排障神器，验收常要求双向平均

### 6.2 OTDR 曲线判读（判读专项核心）

```
背向散射斜线 ──╲__(事件)____╲__(末端反射尖峰)┃
```

| 曲线现象 | 结论 |
|----------|------|
| 斜线整体变陡（阶梯下降） | 熔接点/弯折损耗点（**无反射的纯损耗事件**） |
| 正反射尖峰后阶跃 | 活动连接器（机械接触面） |
| 尖峰后曲线回到更高水平 | **增益现象**（gainer，两段模场直径不同的光纤对接，双向测试可确认真实损耗） |
| 曲线直接坠到底 | **断纤/断裂** |
| 末端出现大尖峰 + 之后还有"假曲线" | 末端反射后的**鬼影（ghost）**，非真实事件 |
| 事件位置与实际对不上 | 折射率 **IOR 设错** → 长度系统性偏差（IOR 偏大 → 测得偏短） |
| 起始段一大坨 | **盲区**（事件盲区/衰减盲区），近端事件需借助盲区光纤/发射缆测 |

> OTDR 精髓：**定位靠它，定值（验收损耗）靠 OLTS**；一个事件的双向 OTDR 平均值才接近真值。
