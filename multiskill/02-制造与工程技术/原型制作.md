原型制作（Prototype Modelling）· 项目精通总纲

所属领域：制造与工程技术
适合人群：零基础到备赛选手、模型制作方向技工、工业设计与手工制作爱好者
本仓库定位：原型制作是本项目的主赛道，本仓库另有配套的中文保姆级教程、赛题解析与离线学习工具，均在首页可达；本篇是全技能库中的项目级速览，细节请读主教程。

一、项目是什么

原型制作项目考察选手按设计图纸制作高完成度实体模型或功能原型的能力：识读设计图与比例换算、选材下料、手工与机械成形、翻模浇注、装配调试、表面处理与喷漆装饰，最终交付一件尺寸准确、表面精致、功能或机构可动的作品。材料以木材、塑料与泡沫为主，金属为辅。它与日常所说的"做手工"差别很大：手工作品好看即可，赛场要求每个尺寸对应图纸比例、每个圆角与分型线经得起近距离检视，工序规划与表面质量才是分水岭。

这个项目的气质介于工坊与画室之间：既要钳工式的精准，又要漆工式的耐心。失分大头通常不在大形，而在边缘、接缝与漆面这类细节。

训练核心是把基础工序练到稳定，把可动机构与外观细节的手感分别练透。评委是拿着图纸近看作品的，大形七分细节三分的误区每年都在吞掉大量分数。

二、竞赛怎么比

典型赛程为四天，按图纸独立完成一件作品，常见结构如下：
1. 识图与规划：读懂多视图设计图与比例要求，制定材料清单与工序计划。
2. 坯体制作：锯切、车铣、雕刻、打磨成形，主尺寸与比例计分。
3. 细节加工：圆角、分型线、凹槽、格栅等特征的精修与一致性。
4. 翻模与浇注：硅橡胶制模与树脂浇注小件，常见于重复性部件。
5. 装配与机构：转轴、抽拉、开合等活动件的调整，保证动作顺畅。
6. 表面与涂装：底漆、打磨、面漆、分色遮蔽与装饰贴图。
评分按尺寸与比例、表面质量、装配与功能、外观还原度、工作规范分档计分；可动机构失效是重灾失分区。
赛场策略的核心：先做工序与固化时间的总排程，坯体与机构优先，涂装分色方案在动手前定稿，把细节精修与检查的工时写进计划而不是挤剩余时间。

三、核心能力域

1. 识图与比例：多视图与剖视解读、比例换算、尺寸链在模型上的落位。
2. 材料知识：松木与椴木、密度板、ABS 与亚克力、泡沫与树脂的切削与粘接特性。
3. 手工成形：锯、刨、锉、刮、钻的基础功，型面打磨的手感与检测。
4. 测量与样板：卡尺与半径规的使用、自制度样板的检验方法、一致性比对。
5. 机械加工：小型车床与铣床的车铣辅助、激光切割与雕刻机的应用。
6. 塑料成形：亚克力热弯、真空吸塑、热熔焊接与溶剂粘接的工艺控制。
7. 翻模浇注：硅橡胶模具的制作分模、树脂配比与气泡排除、修边整理。
8. 装配与机构：转轴与铰链的配合精度、卡扣与磁吸的固定、活动件的手感调校。
9. 表面处理：腻子与底漆、水磨目数递进、孔隙裂缝与接缝的修复流程。
10. 喷漆涂装：喷枪调节与走枪节奏、遮蔽分色、清漆与质感处理、漆病防治。
11. 装饰细节：贴图与转印、拉丝与做旧、标识与铭牌的粘贴定位。
12. 工序与工时管理：干燥与固化等待时间的排程利用、并行工序设计。
13. 安全与工位：粉尘与溶剂防护、刀具与热工具使用纪律、工位整洁全程计分。
14. 审美判断：形面过渡与细节分寸的品鉴力，靠大量看与比培养。

四、从零到赛场的精通路线

四个阶段是经验参考，顺序不建议颠倒：坯体与打磨的手感没稳之前就去追涂装，缺陷只会被漆面放大。

阶段一：入门（约 1 至 2 个月）
目标：建立手工成形与识图的基本功。
训练内容：
1. 手工具基础：锯切直线与曲线、锉削平面与弧面、钻孔定位。
2. 识图与比例换算训练，从三视图推出坯料分解方案。
3. 木与塑料小件制作：尺寸控制与打磨手感。
4. 粘接剂体系入门：快干、溶剂与热熔的适用与失效。
5. 工位布置与工具管理入门，养成随手归位的习惯。
6. 测量与样板检验方法：卡尺、半径规与自制度样板的比对练习。
验收标准：独立完成一个多件组合的小模型，尺寸对应图纸，接缝均匀。

阶段二：基础固化（约 2 至 3 个月）
目标：固化坯体精修与表面处理的流程。
训练内容：
1. 型面打磨专项：圆角一致性与分型线流畅度的刻意练习。
2. 底漆与水磨流程固化：缺陷修复、目数递进与检验手法。
3. 喷漆入门：喷枪调节、走枪节奏与常见漆病防治。
4. 腻子与缺陷修复专项：孔隙、裂缝与接缝的处理流程。
5. 小型机床训练：车削回转体与铣削平面槽的辅助加工。
6. 建立工序模板：从下料到涂装的标准顺序与检查点。
验收标准：一件坯体加涂装的完整作品，表面目视无明显缺陷，尺寸比例达标。

阶段三：进阶专项（约 3 至 4 个月）
目标：攻坚翻模、机构与综合作品。
训练内容：
1. 翻模浇注专项：分模设计、气泡控制与浇口修整。
2. 可动机构专项：开合门、转轴与抽拉结构的配合与耐久调试。
3. 分色与装饰专项：遮蔽边缘的利落度、贴图定位与做旧质感。
4. 综合作品成套训练：按往届风格完成整件，记录各工序耗时。
5. 综合排程训练：固化等待与并行工序的调度表设计。
6. 多件并行与等待时间利用的效率训练。
验收标准：综合作品机构动作顺畅、分色利落，整件完成度达到赛级观感。

阶段四：竞赛级打磨（约 3 个月，循环进行）
目标：全真模拟固化赛场流程与心理。
训练内容：
1. 按往届题型全真计时四天交付，按分档评分表自评互评。
2. 固定开工流程：识图列件清单、工序与固化时间排程、细节工时预留。
3. 异常处置演练：坯体破损补救、漆面瑕疵返修、机构卡滞的应急调整。
4. 读图与装饰方案限时设计专项：半天内定稿整套外观方案。
5. 体能与心理建设：连续多日精细作业的手部稳定与专注管理。
6. 考前状态管理：材料与工具清单固化，工序模板定稿。
验收标准：模拟赛成绩稳定达到目标水平，失分点全部可追溯并有改进记录。

五、每日与每周训练体系

每日（3 至 5 小时）：半小时识图与工序复盘，其余时间动手；作品拍照留档，当晚记录缺陷与修正。
等待固化的时段做识图、排程与装饰方案设计，时间不许空转。
每周：一次限时作品任务，一次专项（打磨、喷漆或机构轮换），一次复盘：工序模板与漆病记录更新。
每月：一次全真模拟赛并按分档表打分；重做旧类型作品检验手感是否回退。
耗材台账：板材漆料消耗、缺陷类型分布留痕，考前只看台账与错题本。

六、自测清单

1. 能把三视图准确转成分件方案与坯料清单，比例换算无误。
2. 能完成平面与弧面的精细打磨，圆角一致性经样板检验。
3. 能独立完成底漆、水磨与面漆的全流程，表面无橘皮与颗粒堆积。
4. 能完成分色喷漆，遮蔽边缘利落无渗色。
5. 能制作硅橡胶模具并浇注合格小件，气泡与分模线受控。
6. 能调校可动机构，动作顺畅且重复开合不松不卡。
7. 能在限定工时内完成整件作品，细节与外观经近距离检视。
8. 能全程执行粉尘与溶剂防护，工位整理成为习惯。

七、常见失误与避坑

1. 前松后紧：坯体阶段耗光时间，涂装与细节仓促收尾，观感分大额流失。
2. 跳过底漆：直接面漆暴露所有划痕与毛孔，返工成本远高于底漆工序。
3. 机构硬凑：转轴配合不做试装，赛场动作卡滞，功能分全丢。
4. 尺寸不对照：凭感觉做比例，评分按图纸实测，大形再好也失分。
5. 忽视工位分：工具乱放与废料堆积直接影响规范分，随手清理要练成本能。
